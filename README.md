## Why this exists

I'm Tony Sheng — a Chinese language teacher with **6000+ hours of teaching** behind me, now building AI tools and learning systems in public. This is where I keep my thinking permanent: course notes, ideas from reading, and lessons from teaching, all interlinked.

It's not a blog. It's a *digital garden* — a living, evergreen web of notes that grows and cross-references itself over time. Built with [Quartz](https://github.com/jackyzha0/quartz), it publishes my Obsidian vault as a fast, searchable, bilingual website.

## ✨ What you'll find

- **AI & Technology** — LLMs, agents, Claude Code, and the AI builder ecosystem
- **Computer Science** — Course notes from Andrew Ng, Stanford CS336, and more
- **Mathematics & Education** — How people actually learn math, and what AI changes
- **Thinkers** — Karpathy, Sutskever, Dan Koe, Cathie Wood, and others worth following
- **Business & Investing** — Startup thinking, the creator economy, building in public
- **Chinese Teaching** — Insights and quotes from real one-on-one teaching sessions

## 🧱 Built with Quartz

This garden runs on [Quartz v4](https://github.com/jackyzha0/quartz) — a static-site generator that turns Markdown / Obsidian notes into a linked website with backlinks, graph view, full-text search, and dark mode.

## 🚀 Run locally

```bash
git clone https://github.com/shengdabai/tony-knowledge-garden.git
cd tony-knowledge-garden
npm install
npx quartz build --serve
```

Then open `http://localhost:8080`. Requires Node.js ≥ 22.

The published garden lives at **[notes.zturnsgo.com](https://notes.zturnsgo.com/)** — fully searchable, with backlinks and graph navigation.

我是盛长春（Tony Sheng）——一名中文教师，身后是 **6000+ 小时教学经验**，如今在公开构建 AI 工具与学习系统。这里是我让思考变得永久的地方：课程笔记、阅读所得、教学心得，全部相互链接。

这不是博客，而是一座*数字花园*（digital garden）——一张常青、不断生长、自我交叉引用的笔记之网。它由 [Quartz](https://github.com/jackyzha0/quartz) 驱动，把我的 Obsidian 笔记库发布成一个快速、可搜索、中英双语的网站。
