# **📚 教学金句的跨学科回响**

**核心金句**："对于中文来说，你说错语法、说错句子都没关系，只要记住词汇，能说出你想要的东西就可以了。"

| 学科视角 | 理论支撑 | 核心观点 |
| :--- | :--- | :--- |
| **语言学** | Rod Ellis《第二语言习得研究》 | "第二语言学习者会通过一系列'学习者变体'逐步接近目标语言系统，但很少达到完美掌握。" |
| **脑科学** | 斯坦尼斯拉斯·迪昂《精准学习》 | "大脑的学习潜力会减弱，但不会完全消失。哪怕到了五十岁，你也能学会一门新乐器，只是学得比较慢罢了。" |
| **文化学** | 萧伯纳名言 | "沟通最大的问题就在于有人认为已经沟通过了。" |
