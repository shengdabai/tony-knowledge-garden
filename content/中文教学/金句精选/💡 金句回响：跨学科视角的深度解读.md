# **💡 金句回响：跨学科视角的深度解读**

针对核心命题"中国人喜欢赚钱，但是我们又不喜欢很有钱的人"，从多学科视角解析：

| 学科视角 | 核心观点 | 来源 |
| :--- | :--- | :--- |
| **哲学视角** | "自求名利，不欲他有，于有之人，而生憎恚" | 索达吉堪布《入行论讲解》 |
| **心理学视角** | "仇富是社会比较中产生的道德防卫机制" | 赫尔穆特·舍克《嫉妒与社会》 |
| **商业视角** | "嫉妒是幸福的毒药，向上比较是幸福的毒药" | 摩根·豪泽尔《金钱的艺术》 |
