# **05. 金句回响：多学科视角的印证**

| 视角 | 核心观点 | 出处 |
| :--- | :--- | :--- |
| **心理学** | "当价格是零时，人们会非理性地疯狂追求，完全忽略产品的实际价值。" | 丹·艾瑞里（行为经济学家） |
| **经济学** | "价格不仅是商品价值的体现，更是一种筛选机制——它筛选出愿意为优质内容买单的用户。" | 薛兆丰（北京大学教授） |
| **商业** | "'昂贵'的反义词不是'便宜'，而是'免费'。前者在价值体系内，后者暗示'没有价值'。" | 保罗·斯隆（《把你的思维横起来》作者） |
