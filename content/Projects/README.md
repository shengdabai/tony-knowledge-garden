## 🧠 AI / Claude Code 工具链

A curated collection of Claude Code configurations, agents, skills, and MCP integrations。把能找到的好东西都聚在一起。

## 📚 中文教学 / 语言学习

### [ChineseThinking](https://github.com/shengdabai/ChineseThinking)
中文思维训练平台，面向海外学员的结构化学习产品。

### [chinese-teaching-video-system](https://github.com/shengdabai/chinese-teaching-video-system)
开源的 AI 中文教学短视频生产系统：浏览器控制台 + prompt 模板 + FFmpeg 自动化一条龙。

语言学习辅助工具，用 AI 把外语内容转成母语视角的对照阅读。
