# **🔍 高分进阶技巧**

#### **一、三角不等式放缩**
1. **基础放缩**：当$x\in(0,\frac{\pi}{2})$时，$\sin x < x < \tan x$
2. **高阶放缩**：
   - $\sin x \geq x - \frac{x^3}{6}$（$x>0$）
   - $\cos x \geq 1 - \frac{x^2}{2}$（$x\in\mathbb{R}$）

#### **二、多模块交叉综合**

**函数交点问题**：判断$f(x)=\sin x$与$g(x)=|e^x-1|$在$(-2\pi,2\pi)$的交点个数  
**图像分析**：
- $g(x)$在$x>0$时为$e^x-1$（切线为$y=x$），在$x<0$时为$1-e^x$（渐近线$y=1$）
- $\sin x$在$(0,2\pi)$与$g(x)$无交点，在$(-2\pi,0)$有2个交点，原点处1个交点，共3个
