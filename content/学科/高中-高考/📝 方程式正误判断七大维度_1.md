# **📝 方程式正误判断七大维度**

#### **一、核心判断标准**

| **判断维度** | **关键要点** | **典型错误案例** |
|--------------|--------------|------------------|
| **客观存在性** | 反应是否符合事实 | Fe与盐酸反应生成FeCl₃（应为FeCl₂） |
| **守恒关系** | 原子守恒、电荷守恒、得失电子守恒 | 未配平：MnO₂ + HCl → MnCl₂ + Cl₂↑ + H₂O（应为4HCl） |
| **符号规范** | 气体(↑)、沉淀(↓)、可逆符号(⇌) | 电解反应未标注“电解”条件 |
| **物质拆分** | 弱电解质、气体、沉淀不可拆 | 硫化氢拆分为H⁺和S²⁻（H₂S为弱电解质） |
| **漏写反应** | 是否存在多个并行反应 | 忽视氧化还原与复分解的叠加反应 |
| **量比关系** | 少量/过量导致产物差异 | 少量SO₂通入Ca(ClO)₂生成CaSO₃（应为CaSO₄） |
| **条件影响** | 温度、浓度引发质变 | 常温下Na与O₂生成Na₂O₂（应为Na₂O） |

#### **二、高频易错反应示例**
1. **离子拆分错误**：  
   - 石灰乳（Ca(OH)₂）不可拆，澄清石灰水可拆  
   - 硫酸氢钠（NaHSO₄）拆为Na⁺+H⁺+SO₄²⁻，碳酸氢钠（NaHCO₃）拆为Na⁺+HCO₃⁻  

2. **氧化还原与复分解叠加**：  
   - 少量SO₂通入NaClO溶液：  
     **错误**：SO₂ + ClO⁻ + H₂O = SO₄²⁻ + Cl⁻ + 2H⁺  
     **正确**：SO₂ + ClO⁻ + Ca²⁺ + H₂O = CaSO₄↓ + Cl⁻ + 2H⁺（考虑CaSO₄微溶）
