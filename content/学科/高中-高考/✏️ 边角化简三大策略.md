# **✏️ 边角化简三大策略**

#### **1. 角角转化**
- **工具**：三角恒等变换公式（和差角、二倍角、诱导公式）
- **示例**：$\sin(A+B) = \sin(\pi-C) = \sin C$（三角形内角和性质）

#### **2. 边角互化**
- **正弦定理转化**：$a = 2R\sin A, b = 2R\sin B$（边化角）；$\sin A = \frac{a}{2R}$（角化边）
- **余弦定理转化**：$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$（角化边）
- **关键条件**：等式必须为**齐次式**（边或角的次数相同）

#### **3. 边边转化**
- **工具**：完全平方公式、因式分解
- **示例**：$a^2 + b^2 = (a+b)^2 - 2ab$（结合基本不等式求最值）
