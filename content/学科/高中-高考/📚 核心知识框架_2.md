# **📚 核心知识框架**

#### **一、三角函数恒等变换公式体系**

**核心公式分类**
1. **同角基本关系**
   - $\sin^2\alpha + \cos^2\alpha = 1$（平方和关系）
   - $\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$（商数关系）
   - **应用技巧**：见到$\tan\alpha$优先转化为$\frac{\sin\alpha}{\cos\alpha}$

2. **两角和差公式**
   - $\sin(\alpha\pm\beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$
   - $\cos(\alpha\pm\beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$（**符号易错点**：$\cos$展开后符号内外相反）

3. **二倍角公式**
   - $\sin2\alpha = 2\sin\alpha\cos\alpha$
   - $\cos2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$（**三选一原则**：根据题目需求选择形式）

4. **辅助角公式**
   - $a\sin\alpha + b\cos\alpha = \sqrt{a^2+b^2}\sin(\alpha+\varphi)$，其中$\tan\varphi = \frac{b}{a}$
   - **适用条件**：$\sin$与$\cos$的角相同、次数均为1

5. **和差化积与积化和差**（**高分必备**）
   - $\sin\alpha\sin\beta = -\frac{1}{2}[\cos(\alpha+\beta)-\cos(\alpha-\beta)]$
   - $\cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha+\beta)+\cos(\alpha-\beta)]$
   - **推导技巧**：利用两角和差公式相加减推导

#### **二、三角函数图像与性质**

**图像变换与参数关系**

| 变换类型 | 解析式变化 | 图像特征 |
| :------- | :--------- | :------- |
| **左右平移** | $y = \sin(x\pm\varphi)$ | $\varphi>0$向左移，$\varphi<0$向右移 |
| **横向伸缩** | $y = \sin(\omega x)$ | $\omega>1$压缩，$0<\omega<1$伸长 |
| **纵向伸缩** | $y = A\sin x$ | $A>1$伸长，$0<A<1$压缩 |
| **上下平移** | $y = \sin x + k$ | $k>0$上移，$k<0$下移 |

**性质分析框架**（以$y = A\sin(\omega x+\varphi)+B$为例）
1. **定义域**：$x\in\mathbb{R}$（无特殊限制时）
2. **值域**：$[B-A, B+A]$
3. **周期性**：$T = \frac{2\pi}{|\omega|}$
4. **单调性**：令$t = \omega x+\varphi$，转化为$\sin t$的单调区间
5. **对称性**：
   - 对称轴：$\omega x+\varphi = \frac{\pi}{2}+k\pi$
   - 对称中心：$(\frac{k\pi-\varphi}{\omega}, B)$，$k\in\mathbb{Z}$

#### **三、解题方法论**

**恒等变换三大策略**
1. **找特征**：识别关键结构（如$\sin\alpha\cos\alpha$→二倍角，$\sin x\pm\cos x$→辅助角）
2. **凑齐次**：通过$\sin^2\alpha+\cos^2\alpha=1$将式子化为齐次式，再转化为$\tan\alpha$
3. **找角关系**：分析角之间的和差倍分关系（如$\alpha = (\alpha+\beta)-\beta$）

**图像问题四大技巧**
1. **五点作图法**：确定$(0,0),(\frac{\pi}{2},1),(\pi,0),(\frac{3\pi}{2},-1),(2\pi,0)$五个关键点
2. **换元法**：令$t = \omega x+\varphi$，将复合函数转化为基本三角函数
3. **特值法**：对$\varphi$取特殊值（如0，$\frac{\pi}{2}$）简化计算
4. **几何法**：利用三角函数线或单位圆分析大小关系
