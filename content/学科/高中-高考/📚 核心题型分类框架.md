# **📚 核心题型分类框架**

**两大题型体系**  
根据12套真题+5套模拟题（共17套32道大题）的统计分析，信息类文本大题可分为**概括类**（占比约67%）和**论证类**（占比约33%）两大体系，每类下分4种小题型。

| **大类** | **小题型**               | **典型特征**                                                                 | **出现频率**               |
| :------- | :----------------------- | :--------------------------------------------------------------------------- | :------------------------- |
| **概括类** | 1. 单纯概括信息          | 题干信息可直接对应原文，无需转化（如2024新课标二卷"对读者了解这本书的帮助"） | 基础核心题型               |
|          | 2. 下定义                | 需遵循"种差+属概念"格式（如2020年真题）                                     | 披着新形式的基础题         |
|          | 3. 文本特征分析          | 如科普文/新闻/人物通讯的特征术语（模拟题考点）                               | 低频但需预防               |
|          | 4. 找不同/找相同         | 需分别概括A、B材料后对比（2021-2023年真题高频，2024年未考）                 | 2026年可能"回马枪"         |
| **论证类** | 1. 论证结构分析          | 含行文脉络/论证思路/上下文逻辑（2025年一卷新瓶装旧酒题型）                   | 高频重点题型               |
|          | 2. 论证方法分析          | 如举例/对比/因果/比喻论证（2021八省联考真题）                               | 低频基础题型               |
|          | 3. 论证作用分析          | 对论点/论据/论证结构/语言的作用（2024新课标一卷设问反问作用题）             | 近年露骨化趋势             |
|          | 4. 论证特点综合分析      | 需整合结构+方法+语言的综合评价（仅2020年模拟卷考过）                         | 2026年高概率回归题型       |
