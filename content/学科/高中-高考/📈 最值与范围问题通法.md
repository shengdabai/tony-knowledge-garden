# **📈 最值与范围问题通法**

#### **两大转化方向**
1. **角化边**：利用余弦定理转化为边的关系，结合基本不等式
   - 示例：$\cos C = \frac{a^2 + b^2 - c^2}{2ab} \geq \frac{2ab - c^2}{2ab}$（当a=b时取等）

2. **边化角**：利用正弦定理转化为三角函数，结合辅助角公式
   - 示例：$a + b = 2R(\sin A + \sin B) = 4R\sin\frac{A+B}{2}\cos\frac{A-B}{2}$

#### **常见题型与策略**

| 问题类型 | 转化方法 | 核心工具 |
| :------- | :------- | :------- |
| 角度最值 | 余弦定理+基本不等式 | $\cos\theta \geq \frac{1}{2} \Rightarrow \theta \leq 60^\circ$ |
| 边长范围 | 正弦定理+三角函数有界性 | $\sin\theta \in [-1,1]$ |
| 面积最值 | 两边夹一角公式+二次函数 | $S = \frac{1}{2}ab\sin C$ |
