# **💡 解题高分策略**

#### **（一）选择题"秒杀"技巧**
1. **主客观关系判断法**  
   - 出现"决定""根源""基础"等词时，优先选择客观范畴（如物质、实践、规律），排除主观范畴（如意识、理论、经验）  
   - **例外**：世界观决定方法论（二者均为主观范畴）  

2. **一面对两面排除法**  
   - 警惕"变化=发展""意识=正确认识"等错误表述（变化包含好坏，意识有正误之分）  

3. **夸大作用识别法**  
   - 排除"绝对化"表述：如"必然""一定""所有"（除非教材明确绝对化结论，如"真理是客观的"）  

#### **（二）主观题"踩点"公式**
1. **哲学原理+方法论+材料**  
   ```markdown
   原理（如：矛盾特殊性原理）→ 方法论（具体问题具体分析）→ 材料（针对XX问题采取XX措施）  
   ```

2. **小论文题结构模板**  
   ```markdown
   总论点（如：实现人与自然良性互动需尊重规律与发挥主观能动性统一）  
   分论点1（尊重客观规律：结合材料XX做法）  
   分论点2（发挥主观能动性：结合材料XX创新实践）  
   结论（总结方法论意义）  
   ```
