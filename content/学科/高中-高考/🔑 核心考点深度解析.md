# **🔑 核心考点深度解析**

#### **（一）辩证唯物论：探究世界的本质**
1. **核心原理**  
   - **物质决定意识**：客观存在（如国情、规律、实践）决定主观意识（如理论、政策、观念）  
   - **意识能动作用**：人能能动地认识世界（目的性、自觉选择性、能动创造性）和改造世界（指导实践）  
   - **规律客观性**：规律是事物固有的本质联系，不可创造/消灭，但可认识和利用  

2. **主观题答题框架**  
   ```markdown
   ① 物质决定意识→一切从实际出发（结合材料：针对XX问题，立足XX实际）  
   ② 意识能动作用→树立正确意识（结合材料：XX理念/政策指导XX实践）  
   ③ 规律客观性与主观能动性统一→尊重规律+发挥主观能动性（结合材料：遵循XX规律，采取XX措施）  
   ```
#### **（二）唯物辩证法：把握世界的规律**
1. **三大核心板块**  
   - **联系观**：普遍性（用联系观点看问题）、客观性（反对主观臆造联系）、多样性（分析不同条件）、整体与部分关系（立足整体+重视部分）  
   - **发展观**：普遍性（发展是前进性与曲折性统一）、量变与质变（重视量的积累，抓住质变时机）、辩证否定观（扬弃旧事物，推动创新）  
   - **矛盾观**：对立统一规律（矛盾即对立统一）、普遍性与特殊性（共性与个性关系）、主次矛盾与矛盾主次方面（抓重点、看主流）  

2. **易混点辨析**  
   | **概念**       | **区别**                          | **关键词**                     |
   | :------------- | :-------------------------------- | :----------------------------- |
   | 主次矛盾       | 针对"做事情"，强调解决问题        | 关键、重点、中心               |
   | 矛盾主次方面   | 针对"看问题"，强调判断性质        | 主流、本质、方向               |
   | 整体与部分     | 强调整体功能与部分协调           | 全局、系统优化                 |
   | 量变与质变     | 强调发展的状态与过程             | 积累、突破、飞跃               |

#### **（三）认识论：探索认识的奥秘**
1. **实践与认识辩证关系**  
   - **实践是认识的基础**：来源（认识从实践中来）、动力（实践推动认识发展）、检验标准（实践验证真理）、目的（认识服务于实践）  
   - **认识的反复性与无限性**：追求真理是螺旋式上升过程（如：对XX规律的认识从初步到深化）  

2. **真理的特性**  
   - **客观性**：真理是主观与客观相符合的认识，同一条件下真理只有一个  
   - **条件性与具体性**：真理在一定条件下成立，需做到理论与实践具体的历史的统一
