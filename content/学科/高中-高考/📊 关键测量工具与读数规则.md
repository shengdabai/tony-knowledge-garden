# **📊 关键测量工具与读数规则**

#### **一、电表读数规范**

| 电表类型 | 量程选择 | 最小分度值 | 读数规则 | 示例 |
| :------- | :------- | :--------- | :------- | :--- |
| **电压表** | 0-3V | 0.1V | 需估读到下一位（0.01V） | 21格 × 0.1V = 2.10V |
|  | 0-15V | 0.5V | 本位估读（0.1V） | 21格 × 0.5V = 10.5V |
| **电流表** | 0-0.6A | 0.02A | 本位估读（0.01A） | 12格 × 0.02A = 0.24A → 0.25A（指针在中间） |
|  | 0-3A | 0.1A | 需估读到下一位（0.01A） | 12格 × 0.1A = 1.20A → 1.25A（指针在中间） |

#### **二、精密测量仪器**

| 仪器 | 测量原理 | 读数公式 | 误差特点 |
| :--- | :------- | :------- | :------- |
| **游标卡尺** | 主尺+副尺分度差 | 主尺读数+副尺对齐格数×分度值 | 无需估读，精度0.1mm/0.05mm/0.02mm |
| **螺旋测微器** | 固定刻度+可动刻度 | 固定刻度+可动刻度×0.01mm+估读位 | 需估读到0.001mm，精度0.01mm |
