# **🔍 具体函数核心题型**

#### **一、常见函数性质与图像**

| 函数类型       | 核心性质                                                                 | 图像特征                                                                 |
|----------------|--------------------------------------------------------------------------|--------------------------------------------------------------------------|
| **指数函数**   | \(a^x\)（\(a>0,a≠1\)），恒过点\((0,1)\)，单调性由\(a\)决定                | \(a>1\)时单调递增，\(0<a<1\)时单调递减                                  |
| **对数函数**   | \(\log_a x\)（\(a>0,a≠1\)），恒过点\((1,0)\)，与指数函数互为反函数        | \(a>1\)时单调递增，\(0<a<1\)时单调递减，定义域\((0,+\infty)\)           |
| **幂函数**     | \(y=x^k\)，恒过点\((1,1)\)，奇偶性与单调性由\(k\)决定                     | 如\(y=x^3\)（奇函数，单调递增），\(y=x^{-1}\)（奇函数，双曲线）          |
| **三角函数**   | \(\sin x\)（奇函数，周期\(2\pi\)），\(\cos x\)（偶函数，周期\(2\pi\)）    | \(\sin x\)图像关于原点对称，\(\cos x\)图像关于\(y\)轴对称               |
| **类二次函数** | \(a^x + a^{-x}\)（偶函数，最小值为2，基本不等式可证）                     | 图像关于\(y\)轴对称，在\(x=0\)处取最小值                                 |
| **类三次函数** | \(a^x - a^{-x}\)（奇函数，\(a>1\)时单调递增，\(0<a<1\)时单调递减）        | 图像关于原点对称，过原点                                                 |

#### **二、函数图像识别与应用**

**解题步骤**：  
1. **判断奇偶性**：奇函数（如\(x^3\sin x\)）关于原点对称，偶函数（如\(x^2\cos x\)）关于\(y\)轴对称。  
2. **分析特殊点**：如\(x=0\)、\(x=1\)处的函数值，排除不符合选项。  
3. **研究单调性**：通过求导判断函数增减趋势，如\(y=\frac{\ln x}{x}\)在\((0,e)\)递增，\((e,+\infty)\)递减。  

**典型例题**：  
- **已知函数奇偶性求参数**：若\(f(x)=\frac{e^x - e^{-x}}{e^x + e^a}\)为偶函数，则\(a=2\)（利用\(f(1)=f(-1)\)或奇函数除以奇函数为偶函数的性质）。  
- **函数图像判断**：\(f(x)=x^3\cos x\)为奇函数，排除B、D；在\(x\in(0,\frac{\pi}{2})\)时\(f(x)>0\)，选A。
