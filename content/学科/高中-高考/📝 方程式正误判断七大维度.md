# **📝 方程式正误判断七大维度**

#### **一、客观反应规律**
- **错误示例**：Fe与稀盐酸反应生成Fe³⁺（正确：Fe + 2H⁺ = Fe²⁺ + H₂↑）  
- **核心原则**：金属与非氧化性酸反应生成H₂和低价态金属离子  

#### **二、三大守恒验证**
1. **原子守恒**：反应前后各元素原子个数相等  
2. **电荷守恒**：离子方程式左右两边电荷代数和相等  
3. **电子守恒**：氧化还原反应中得失电子数相等  

**示例**：酸性KMnO₄氧化H₂C₂O₄（正确配平）  
2MnO₄⁻ + 5H₂C₂O₄ + 6H⁺ = 2Mn²⁺ + 10CO₂↑ + 8H₂O  

#### **三、物质拆分规则**

| **物质类型** | **拆分原则** | **示例** |
|--------------|--------------|----------|
| 可溶性强电解质 | 拆为离子 | NaCl → Na⁺ + Cl⁻ |
| 弱电解质（弱酸/弱碱/H₂O） | 不拆 | H₂CO₃、NH₃·H₂O、H₂O |
| 难溶物/气体/单质 | 不拆 | CaCO₃、CO₂、Fe |
| 微溶物（如Ca(OH)₂） | 澄清溶液拆，悬浊液不拆 | 石灰水拆为Ca²⁺ + 2OH⁻，石灰乳不拆 |

#### **四、量比关系陷阱**
- **少量CO₂通入NaOH溶液**：CO₂ + 2OH⁻ = CO₃²⁻ + H₂O  
- **过量CO₂通入NaOH溶液**：CO₂ + OH⁻ = HCO₃⁻
