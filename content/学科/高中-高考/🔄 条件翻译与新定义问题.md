# **🔄 条件翻译与新定义问题**

#### **一、常见条件翻译**

| 条件描述                     | 数学翻译                                                                 |
|------------------------------|--------------------------------------------------------------------------|
| 直线为两曲线公切线           | 设切点求导，切线方程相等（斜率、截距均相等）                             |
| 函数在区间单调递增           | \(f'(x) \geq 0\)在区间内恒成立                                           |
| 函数有极大值点和极小值点     | \(f'(x)=0\)有两个不等实根，且导函数在根两侧异号                         |
| \(f'(x) + f(x) < 0\)         | 构造\(g(x)=e^x f(x)\)，则\(g'(x)=e^x(f'(x)+f(x)) <0\)，\(g(x)\)递减      |

#### **二、新定义创新题**

**解题关键**：理解新定义内涵，转化为已有知识。  
- **不动点问题**：若\(f(f(y_0))=y_0\)且\(f\)单调，则\(f(y_0)=y_0\)。  
- **利普希茨条件**：存在\(L\in(0,1)\)，使得\(|f(x_1)-f(x_2)| \leq L|x_1 -x_2|\)，可用于证明数列收敛性。
