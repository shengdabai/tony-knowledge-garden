# 📐 空间直角坐标运算

已知**a**=(x₁,y₁,z₁)，**b**=(x₂,y₂,z₂)，则
- **线性运算**
    - `\[ \boldsymbol{a} \pm \boldsymbol{b} = (x_1 \pm x_2, y_1 \pm y_2, z_1 \pm z_2) \]`
    - `\[ \lambda \boldsymbol{a} = (\lambda x_1, \lambda y_1, \lambda z_1) \]`
- **数量积**：`\[ \boldsymbol{a} \cdot \boldsymbol{b} = x_1 x_2 + y_1 y_2 + z_1 z_2 \]`
- **模长**：`\[ |\boldsymbol{a}| = \sqrt{x_1^2 + y_1^2 + z_1^2} \]`
- **夹角公式**：`\[ \cos \langle \boldsymbol{a}, \boldsymbol{b} \rangle = \frac{\boldsymbol{a} \cdot \boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|} = \frac{x_1 x_2 + y_1 y_2 + z_1 z_2}{\sqrt{x_1^2 + y_1^2 + z_1^2} \sqrt{x_2^2 + y_2^2 + z_2^2}} \]`
- **平行、垂直条件**
    - **a**∥**b**(**b**≠0)⇒x₁=λx₂,y₁=λy₂,z₁=λz₂
    - **a**⊥**b**⇒x₁x₂+y₁y₂+z₁z₂=0
