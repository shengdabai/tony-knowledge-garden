# 🔄 程序框图

#### 概念与符号
- **概念**：用通用图形符号构成的图表示算法。
- **符号及功能**：

| 图形符号 | 名称               | 功能描述                                                                 |
|----------|--------------------|--------------------------------------------------------------------------|
| ⌈ ⌋      | 终端框（起止框）   | 表示算法的起始与结束                                                     |
| ▱        | 输入、输出框       | 表示算法输入和输出的信息                                                 |
| ▭        | 处理框（执行框）   | 赋值、计算                                                               |
| ◇        | 判断框             | 判断条件是否成立，成立标“是”/“Y”，不成立标“否”/“N”                      |
| ↓→       | 流程线             | 连接程序框                                                               |
| ⟳        | 循环框             | 重复操作与运算                                                           |
| ○        | 连结点             | 连接程序框图的两部分                                                     |
| ------□  | 注释框             | 帮助理解                                                                 |

#### 画图规则
- 使用标准的框图符号
- 按从左到右、从上到下方向绘制
- 除判断框外，多数程序框图只有一个进入点和一个退出点
- 判断框“是”与“否”分支有且仅有两个结果；多分支可能有多种结果
- 图形符号内语言需简练清晰
