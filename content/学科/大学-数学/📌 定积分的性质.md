# 📌 定积分的性质

1. \(\int_{a}^{b}kf(x)dx = k\int_{a}^{b}f(x)dx\)（\( k \)为常数）  
2. \(\int_{a}^{b}[f_1(x) \pm f_2(x)]dx = \int_{a}^{b}f_1(x)dx \pm \int_{a}^{b}f_2(x)dx\)  
3. \(\int_{a}^{b}f(x)dx = \int_{a}^{c}f(x)dx + \int_{c}^{b}f(x)dx\)（\( a < c < b \)）  
4. **奇偶函数性质**：  
   - 若\( f(x) \)为偶函数，则\(\int_{-a}^{a}f(x)dx = 2\int_{0}^{a}f(x)dx\)  
   - 若\( f(x) \)为奇函数，则\(\int_{-a}^{a}f(x)dx = 0\)
