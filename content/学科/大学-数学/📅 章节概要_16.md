# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **童年集卡经历引发思考**  

讲述者以自身90后童年集108个水浒好汉卡的经历展开，提到自己最喜欢林冲卡且第一张就集到林冲，但后续集卡越来越难，即便吃到嘴起泡也无法集齐。由此产生疑问，集齐108张卡是否真如商家所说吃108包泡面就行，怀疑这是商业陷阱，进而引出要用建模方式解决集卡小问题，并决定先简化为集5张卡的模型。  

[00:01:17](https://getnotes.seek:77) **5张卡集卡模型初步计算**  

引导听众猜测集齐金木水火土5个英雄需吃多少包方便面后，开始具体计算。指出打开第一包方便面肯定能拿到新卡片，假设第一个拿到“金”英雄。对于第二个英雄，有1/5概率还是“金”，4/5概率是其他新英雄，所以预期要1÷4/5 = 1.2包才能拿到新英雄。  

[00:02:30](https://getnotes.seek:150) **5张卡集卡模型深入计算**  

说明已有两个英雄后，拿到第三个新英雄的概率变为3/5，预期为5/3 ≈ 1.66包。依此类推，集到最后一个英雄时，因已有4个英雄，只有1/5概率集到新英雄，预期需5包。最后将每次预期相加，得出集齐5个英雄预期要吃(1 + 1.2 + 1.66 + 2.5 + 5)包，简化式子为5×(1/5 + 1/4 + 1/3 + 1/2 + 1)，约11包，即要吃2.3倍英雄量的方便面。  

[00:04:06](https://getnotes.seek:246) **模型拓展至108张卡的思考**  

提出从5张卡集卡模型得出吃2.3倍英雄量，那么108张卡要吃多少包方便面的问题，引发思考集卡数量增加时，吃的总包数如何变化。指出108张卡集卡模型与5张卡类似，只需把5换成108，式子变为108×(1/108 + 1/107 + … + 1/2 + 1)，要用计算机帮忙计算。  

[00:04:41](https://getnotes.seek:281) **108张卡集卡模型计算与结论**  

介绍用Wolfram Alpha网站计算108张卡集卡模型，算出结果为5.26倍英雄量，意味着要吃500多包方便面。通过对比5张卡和108张卡的情况，得出随着集卡数量增加，吃的英雄量倍数大幅增长的结论，揭示商家集卡活动背后的数学逻辑，体现商家利用此增加消费者购买量的小心机。  

[00:06:03](https://getnotes.seek:363) **集卡问题的进阶思考**  

提出若集卡数量进一步增加，如200个、500个、1000个甚至100万个英雄，吃的英雄量倍数是否会趋于无穷的问题，这是很好的数学思维，即从有限推往无限。指出集卡公式中前面的集卡数量是可控的，不可控部分是1 + 1/2 + 1/3 + … + 1/n这样的数列。  

[00:07:15](https://getnotes.seek:435) **调和级数的引入与分析**  

说明上述数列是数学中的调和级数，项为1÷K（K从1到无穷）。通过软件画出调和级数的函数图像，展示其是缓慢上升的。数学上可证明调和级数不收敛，即N趋于无穷时，数值趋于无穷。例如集100万个英雄，把N换成100万，可算出要吃14倍英雄量，即1400万包方便面。  

[00:09:44](https://getnotes.seek:584) **集卡问题在生活中的应用总结**  

总结集卡问题案例在生活中的应用，一是面对商家集满多少打折等集邮行为，要先计算是否合算；二是以有人想集齐12星座男女朋友为例，讽刺此类“集邮癖”行为，建议通过问其类似集卡数学问题测试其思维，避免盲目跟风此类行为，倡导依靠数学在生活中变得聪明敏锐，不被骗。
