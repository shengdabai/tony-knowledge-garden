# 向量加法

- **定义**：求两个向量和的运算。  
- **法则**：  
  - **三角形法则**：首尾相接，和向量为第一个向量起点指向第二个向量终点。  
  - **平行四边形法则**：共起点为邻边作平行四边形，和向量为共起点的对角线。  
- **运算律**：  
  - 交换律：$\vec{a} + \vec{b} = \vec{b} + \vec{a}$  
  - 结合律：$(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$  
- **模的关系**：$||\vec{a}| - |\vec{b}|| \leq |\vec{a} + \vec{b}| \leq |\vec{a}| + |\vec{b}|$  
  - 当$\vec{a}$与$\vec{b}$同向时，$|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|$；  
  - 当$\vec{a}$与$\vec{b}$反向且$|\vec{a}| < |\vec{b}|$时，$|\vec{a} + \vec{b}| = |\vec{b}| - |\vec{a}|$。
