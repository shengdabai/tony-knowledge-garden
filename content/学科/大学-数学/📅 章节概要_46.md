# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **引入高考不等式题目及常规解法**  
讲解者表示要通过由易到难的题目展示数学魅力，引出高考题√(8 - 2x²) - x > -1 。指出学生通常因根号困扰，会将其单独留下，变形为√(8 - 2x²) > x - 1 ，进而转化为不等式组{8 - 2x² ≥ 0 ，(8 - 2x²) > (x - 1)²}求解，此为固化思维做题的结果，虽能解题，但无法感受数学魅力。
[00:01:37](https://getnotes.seek:97) **构造函数与图形转化**  
讲解者提出新解法，构造函数Y = √(8 - 2x²) 和Y = x - 1 。对Y = √(8 - 2x²) 变形，得到x²/4 + Y²/8 = 1（Y≥0），其图形为半个椭圆，Y = x - 1 是斜率为1且过点（1,0）的直线。解不等式就变为判断椭圆在直线上方部分，将解不等式问题转化为解方程求交点坐标问题，体现等式与不等式相互转化的魅力。
[00:03:08](https://getnotes.seek:188) **题目变化与数形结合优势**  
讲解者将不等式中的 -1 变为 A ，指出常规做法会因出现变数 A 而面临复杂的分段讨论。而通过图形，可清晰看到直线Y = x + A 作为平行直线系移动时与椭圆的位置关系。当直线与椭圆相切时，求出A = 2√3 ，还有另外两个关键点A = 2 和 A = -2 ，据此可轻松得出不同A取值范围下不等式的解，展示了数形结合在应对题目变化时的优势。
[00:04:48](https://getnotes.seek:288) **不等式拓展问题求解**  
讲解者继续拓展题目，若不等式解为空集，从图可知A ≥ 2√3 ；若解为 -2 到 2 ，则A ≤ -2 。通过图形，这些看似复杂的问题变得一目了然，进一步体现数形结合在解决不等式相关拓展问题上的有效性。
[00:06:22](https://getnotes.seek:382) **方程相关问题探讨**  
讲解者将不等式变为方程√(8 - 2x²) = x + A ，提出若方程有解、只有一个解、无解、有两个解等不同情况求A范围的问题。以方程有解为例，即直线与椭圆有交点，得出A范围是[-2, 2√3] ；对于方程只有一个解，需考虑直线与椭圆只有一个交点的情况，得出A = 2√3 或 A ∈ (-2, 2) ，强调开闭区间的细节，说明通过图形可解决这些复杂问题，再次突出数形结合的重要性。
[00:09:22](https://getnotes.seek:562) **总结数形结合的意义**  
讲解者总结，通过该题目展示了数形结合的魅力，能将复杂问题直观化、抽象问题简单化，是新高考强调的基本思想方法，鼓励学生在学习数学时善于运用数形结合，以获得更好的学习体验。
