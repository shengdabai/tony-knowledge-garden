# 📊 椭圆的几何性质（以标准方程\(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）为例）

|性质|内容|
|----|----|
|对称性|中心为\((0,0)\)，对称轴为\(x\)轴、\(y\)轴|
|焦点|\((\pm c, 0)\)，其中\(c^2 = a^2 - b^2\)|
|顶点|\((\pm a, 0)\)，\((0, \pm b)\)|
|范围|\(|x| \leq a\)，\(|y| \leq b\)|
|焦距|\(|F_1F_2| = 2c\)|
|离心率|\(e = \frac{c}{a} = \sqrt{1 - \frac{b^2}{a^2}}\)（\(0 < e < 1\)）|
|长轴长| \(2a\) |
|短轴长| \(2b\) |
|准线方程| \(x = \pm \frac{a^2}{c}\) |
|焦半径|\(|PF_1| = a + ex_0\)，\(|PF_2| = a - ex_0\)（\(P(x_0, y_0)\)为椭圆上一点）|
