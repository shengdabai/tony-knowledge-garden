# 三、周期性

**定义**  
设$f(x)$定义域为$D$，若$\exists T \neq 0$，对$\forall x \in D$有$f(x+T) = f(x)$，则$T$为周期  

**常见周期公式**  
| 条件                          | 周期 |
|-------------------------------|------|
| $f(x+T) = -f(x)$              | $2T$ |
| $f(x+T) = \frac{1}{f(x)}$     | $2T$ |
| $f(x+T) = -\frac{1}{f(x)}$    | $2T$ |
| $f(x+T) = f(x-T)$             | $2T$ |
| $f(x+a) = f(x+b)$             | $\vert a-b \vert$ |
