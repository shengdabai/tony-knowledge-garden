# 基本不等式变形公式汇总

| 公式类型       | 表达式                                                                 |
|----------------|------------------------------------------------------------------------|
| 平方和与积     | \(a^2 + b^2 \geq 2ab\)；\((a - b)^2 \geq 0 \Leftrightarrow a^2 + b^2 \geq 2ab\) |
| 和与积的关系   | \(ab \leq \left(\frac{a + b}{2}\right)^2\)；\(\frac{a + b}{2} \geq \sqrt{ab}\)   |
| 倒数和         | \(\frac{a}{b} + \frac{b}{a} \geq 2\)（\(a \cdot b > 0\)）                 |
| 其他变形       | \(\frac{a^2}{b} \geq 2a - b\)（\(a \geq 0, b > 0\)）；\(\frac{b^2}{a} + \frac{a^2}{b} \geq a + b\)（\(a,b > 0\)） |
