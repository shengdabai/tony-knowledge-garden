# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **高考绝对值题目得分率低的原因探讨**  
讲师指出近几年高考常出现与绝对值有关的题目，本想送分但得分率低，经分析是学生对绝对值概念理解不到位。绝对值定义初一上册就学，讲师让大家回忆其定义，并准备重温。  
[00:00:37](https://getnotes.seek:37) **绝对值的定义回顾**  
讲师详细阐述绝对值的定义，当\(A>0\)时，\(\vert A\vert = A\)；\(A<0\)时，\(\vert A\vert = -A\)；\(A = 0\)时，\(\vert A\vert = 0\)，用文字表述为正数绝对值是本身，负数绝对值是相反数，\(0\)的绝对值是\(0\)。  
[00:01:22](https://getnotes.seek:82) **绝对值的几何意义讲解**  
讲师讲解绝对值的几何意义，在数轴上，若一个数坐标是\(A\)，\(\vert A\vert\)是该点离开原点的距离，因为是距离，所以\(\vert A\vert \geq 0\)，是数学三大非负数之一。  
[00:02:07](https://getnotes.seek:127) **对绝对值定义的深入剖析**  
讲师强调高中虽不再学绝对值定义，但高考常考相关内容，学生却常出错。需对定义深刻剖析，一是\(\vert A\vert \geq 0\)，二是要避免认为\(\vert A\vert = \pm A\)这种错误判断，这是学生出错根源。  
[00:02:54](https://getnotes.seek:174) **绝对值与充要条件的联系及题目分析**  
讲师提出高中学充要条件会与绝对值对接，以\(\vert A\vert > A\)与\(A < 0\)是充要条件为例，说明数学常利用复杂与简单的转化出题，让学生容易掉入陷阱。  
[00:03:37](https://getnotes.seek:217) **绝对值在竞赛题中的应用实例（一）**  
讲师以一道高中竞赛题\(\frac{X}{\vert1 + X\vert} > \frac{X}{1 + X}\)为例，说明若对绝对值概念理解深刻，可快速将其转化为\(\frac{X}{1 + X} < 0\)，进而得出\(X(1 + X) < 0\)，答案为\(-1 < X < 0\)，体现对概念深刻理解的重要性。  
[00:04:15](https://getnotes.seek:255) **绝对值在竞赛题中的应用实例（二）**  
讲师给出方程\(\vert X - 1\vert + \vert X - 2\vert = 1\)，讲述一般学生通过找零点\(X - 1 = 0\)和\(X - 2 = 0\)，将数轴分成三段讨论，但常出错。从绝对值几何意义理解，此方程表示数轴上一点\(X\)到\(1\)和\(2\)的距离之和为\(1\)，所以\(1\leq X\leq 2\)是方程的解。  
[00:05:31](https://getnotes.seek:331) **对绝对值方程的拓展分析**  
讲师对上述方程进行拓展，当把方程右边的\(1\)改成\(\frac{1}{2}\)时，从几何意义可知数轴上不存在一点到\(1\)和\(2\)的距离之和为\(\frac{1}{2}\)，所以方程无解；若改成\(2\)，通过分析可知方程有两个解\(0.5\)和\(2.5\)。  
[00:06:47](https://getnotes.seek:407) **绝对值在高考题中的应用及解题思路**  
讲师讲解高考题\(\vert X - 1\vert + \vert X - 2\vert > A\)恒成立求\(A\)的范围，此类不等式含\(X\)和\(A\)两个变量较难。可把\(A\)看成普通数，将\(Y = \vert X - 1\vert + \vert X - 2\vert\)看成函数，从数轴可知该函数最小值为\(1\)，因为所有值都大于\(A\)，所以只要最小值大于\(A\)命题就成立，得出\(1 > A\)。  
[00:09:52](https://getnotes.seek:592) **总结解决含两个变量不等式的技巧**  
讲师总结此类含两个变量不等式问题的解决技巧，即固定一个变量，把握好基本概念和变量关系，即使题目难度大，也能轻松解决。
