# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **高考命题规律与120分分析**  
讲座开场，说话人表示要透露高考冲刺两个重要秘密。先阐述高考命题遵循3:5:2原则，30%基础分、50%中档题、20%难题，难度系数0.55 。经计算，基础分与中档题共120分，这部分对正常高中生是有章可循的送分题。然而，很多同学未得120分，原因一是自身不学习、偷懒，二是做题策略有误，把会做的题做错，去做不会做的题。说话人强调只要踏实学习、全情投入，每个学生都能轻松拿到这120分。 

[00:03:02](https://getnotes.seek:182) **高考难题特点与另一命题规则**  
说话人接着指出20%难题共30分，是高考选拔性考试拉开差距的部分，这30分防不胜防，无数学竞赛基础很难得到。随后透露高考另一秘密，每个题目得分率不能低于20%，否则会被判为废题，追究命题人责任。为防止题目成为废题，命题人会在难题前设置简单部分，让考生能得两三分，引出“不会也能得3分”的冲刺得分策略。 

[00:05:01](https://getnotes.seek:301) **“不会也能得3分”策略讲解与实例分析**  
说话人强调考生要抱定得分心态，做题是为得分。以全国高考数学试卷压轴题为例，该题是开放性题目，问是否存在正整数M满足条件。因高考评价需公平公正，“不存在需说明理由”标准难统一，所以直接写“存在”可得3分。接着分析数列所有项小于常数意味着数列递减，求出数列第一项小于常数从而得出M值，又可得8分。说话人还提到要想得满分需证明数列递减，通性通法是证明BN + 1 - BN < 0 。 

[00:11:35](https://getnotes.seek:695) **高考考察倾向与满分证明思路**  
说话人提醒考生高考考察通性通法，淡化考试技巧，不要过分偏重独门秘籍。对于证明数列递减以得满分的情况，需用通性通法证明BN + 1 - BN < 0 。列出BN和BN + 1的表达式，相减后得到a2N + 2的平方加上a2N + 3的平方，减去an + 1的平方，再代入公式。即便不会证明，也可多写相关内容，利用高考阅卷老师心理争取分数，最后通过数学放缩法原理可证明数列递减。 

[00:15:36](https://getnotes.seek:936) **过往高考题抢分策略回顾与总结**  
说话人提及自己写的《高考抢分36计》，书中列举不择手段得分策略。以某一年高考压轴题为例，把已知改成“因为”，一字不漏罗列条件即可得3分。最后总结本节课的高考冲刺得分策略“不会也能得3分”，希望对同学们有所启发。
