# 三、对称问题

#### 1. 点关于点对称
- 点 \(P(x_1,y_1)\) 关于点 \(M(x_0,y_0)\) 的对称点坐标为 \((2x_0-x_1, 2y_0-y_1)\)  

#### 2. 点关于直线对称
- **对称轴与对称点坐标对应表**  

| 对称轴方程       | 点 \((a,b)\) 的对称点坐标       |
|------------------|--------------------------------|
| \(x\) 轴          | \((a,-b)\)                     |
| \(y\) 轴          | \((-a,b)\)                     |
| \(x+y+c=0\)      | \((-b-c,-a-c)\)                |
| \(y=x\)          | \((b,a)\)                      |
| \(y=-x\)         | \((-b,-a)\)                    |
| \(x=m\)          | \((2m-a,b)\)                   |
| \(y=n\)          | \((a,2n-b)\)                   |

#### 3. 直线关于直线对称
- **原直线与对称直线对应表（原直线方程为 \(f(x,y)=0\)）**  

| 对称轴方程       | 对称直线方程               |
|------------------|--------------------------|
| \(x\) 轴          | \(f(x,-y)=0\)            |
| \(y\) 轴          | \(f(-x,y)=0\)            |
| \(x+y+c=0\)      | \(f(-y-c,-x-c)=0\)       |
| \(y=x\)          | \(f(y,x)=0\)             |
| \(y=-x\)         | \(f(-y,-x)=0\)           |
| \(x=m\)          | \(f(2m-x,y)=0\)          |
| \(y=n\)          | \(f(x,2n-y)=0\)          |
