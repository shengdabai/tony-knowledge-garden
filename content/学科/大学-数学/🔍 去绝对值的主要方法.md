# 🔍 去绝对值的主要方法

| 方法       | 适用场景                          | 公式/步骤                                                                 |
|------------|-----------------------------------|--------------------------------------------------------------------------|
| 公式法     | \(|x| < a\) 或 \(|x| > a\)（\(a>0\)） | \(|x| < a \Leftrightarrow -a < x < a\)；\(|x| > a \Leftrightarrow x < -a\) 或 \(x > a\) |
| 定义法     | 含绝对值的函数或方程              | 分\(x \geq 0\)和\(x < 0\)讨论，如\(|x| = \begin{cases} x & (x \geq 0) \\ -x & (x < 0) \end{cases}\) |
| 平方法     | 不等式两边非负时                  | 两边平方去绝对值，如\(|ax + b| \leq c \Rightarrow (ax + b)^2 \leq c^2\)    |
| 零点分段法 | 含多个绝对值的表达式              | 令绝对值内式子为零，划分区间后分段讨论                                  |
