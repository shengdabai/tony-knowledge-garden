# 🎯 定积分的概念与几何意义

- **定义**：函数\( f(x) \)在区间\([a,b]\)上的定积分\(\int_{a}^{b}f(x)dx\)定义为分割、求和、取极限的过程：\[
\int_{a}^{b}f(x)dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(\xi_i) \Delta x
\]
其中\( a=x_0 < x_1 < \dots < x_n = b \)，\(\Delta x = \frac{b-a}{n}\)，\(\xi_i \in [x_{i-1},x_i]\)。

- **几何意义**：  
  - 当\( f(x) \geq 0 \)时，\(\int_{a}^{b}f(x)dx\)表示由曲线\( y=f(x) \)、直线\( x=a \)、\( x=b \)及x轴围成的**曲边梯形面积**。  
  - 当\( f(x) < 0 \)时，定积分取负值，此时面积需取绝对值：\( S = -\int_{a}^{b}f(x)dx \)。
