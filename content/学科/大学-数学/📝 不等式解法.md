# 📝 不等式解法

#### 🔄 核心思路
- 同解变形：分式化整式、高次化一次、无理化有理

#### 📊 解有理不等式

| 类型               | 解法                                                                 |
|--------------------|----------------------------------------------------------------------|
| 一元一次不等式     | 直接求解                                                             |
| 一元二次不等式     | 计算判别式\(\Delta = b^2 - 4ac\)，结合二次函数图像求解                     |
| 一元高次不等式     | 数轴标根法：化正→求根→标根→穿根（奇穿偶回）→写解集（注意端点值）         |
| 分式不等式         | \(\frac{f(x)}{g(x)} > 0 \Leftrightarrow f(x)g(x) > 0\)；\(\frac{f(x)}{g(x)} < 0 \Leftrightarrow f(x)g(x) < 0\)；\(\frac{f(x)}{g(x)} \geq 0 \Leftrightarrow \begin{cases} f(x)g(x) \geq 0 \\ g(x) \neq 0 \end{cases}\) |

#### 📈 一元二次不等式解法（\(a > 0\)）

| \(\Delta = b^2 - 4ac\) | 方程\(ax^2 + bx + c = 0\)的根 | \(ax^2 + bx + c > 0\)的解集 | \(ax^2 + bx + c < 0\)的解集 |
|-------------------------|------------------------------|------------------------------|------------------------------|
| \(\Delta > 0\)          | 不等实根\(x_1, x_2\)（\(x_1 < x_2\)） | \(\{x | x < x_1 或 x > x_2\}\) | \(\{x | x_1 < x < x_2\}\)     |
| \(\Delta = 0\)          | 相等实根\(x_1 = x_2\)         | \(\{x | x \neq x_1\}\)        | \(\varnothing\)               |
| \(\Delta < 0\)          | 无实根                       | \(\mathbf{R}\)                | \(\varnothing\)               |
