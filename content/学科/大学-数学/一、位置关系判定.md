# 一、位置关系判定

- **联立方程法**：直线 \(Ax + By + C = 0\) 与圆锥曲线 \(f(x,y) = 0\) 联立，消去 \(y\) 得一元二次方程 \(ax^2 + bx + c = 0\)（\(a \neq 0\)），通过判别式 \(\Delta = b^2 - 4ac\) 判定：  

| **曲线类型** | \(\Delta > 0\)       | \(\Delta = 0\)       | \(\Delta < 0\)       | 特殊情况（一个交点）          |
|--------------|---------------------|---------------------|---------------------|-----------------------------|
| **椭圆**     | 相交（两个交点）     | 相切（一个交点）     | 相离（无交点）       | -                           |
| **双曲线**   | 相交（两个交点）     | 相切（一个交点）     | 相离（无交点）       | 直线与渐近线平行（一个交点） |
| **抛物线**   | 相交（两个交点）     | 相切（一个交点）     | 相离（无交点）       | 直线与对称轴平行（一个交点） |
- **注意**：“相切”是“只有一个公共点”的**充分非必要条件**（双曲线和抛物线需额外考虑特殊直线）。
