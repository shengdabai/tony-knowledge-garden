#### 内容总结
**数学的神奇魅力**
* **折纸问题**：在央视《实话实说》节目中提出，一张纸对折1次厚度增加2倍，对折2次变为原来4倍，若对折64次，其高度可达地球到月球的高度，可利用等比数列公式测算，展现数学神奇。
* **国际象棋棋盘米粒问题**：国际象棋发明于古印度，皇帝欲奖励发明者，发明者要求在棋盘64个格子里，第1格放1粒米，第2格放2粒，第3格放4粒，依此类推，每格是上一格米数的2倍。通过等比数列求和公式可知，总数为2的64次方减1，是全世界大米产量的981倍，国王因无知被捉弄，凸显数学神奇。

**探寻数学源头的重要性**
* **韦达定理**：初中所学的韦达定理，对于方程\(AX² + BX + C = 0\)（有两根\(X1\)、\(X2\)），有\(X1 + X2 = -B/A\)，\(X1×X2 = C/A\) 。该定理因韦达发现得名。其原理基于多项式分解法则，若方程有两根，多项式\(AX² + BX + C\)可分解为\(A×(X - X1)×(X - X2)\)，展开后根据同次项系数相等得出定理内容。掌握其源头，即使忘记定理，也能推导得出，还能据此推出一元三次方程乃至一元N次方程根与系数的关系。
* **三角函数公式推导**：三角函数众多公式常让学生痛苦，实则无需死记硬背。其源头可从单位圆推导得出，如通过单位圆构建角度\(\alpha\)、\(\beta\)，利用两点间距离公式推导出\(\sin(\alpha - \beta)\)的公式，进而依次推出\(\sin(\alpha + \beta)\)、\(\cos(\alpha - \beta)\)、\(\cos(\alpha + \beta)\)等公式。令\(\alpha = \beta\)，可得出倍角公式，如\(\sin2\alpha = 2\sin\alpha\cos\alpha\) 、\(\cos2\alpha = \cos²\alpha - \sin²\alpha\)等，还能推出降幂公式。由\(\sin(\alpha + \beta)\)与\(\cos(\alpha + \beta)\)可推出正切两角和与差公式及二倍角正切公式等。掌握源头，可轻松学好三角函数。
