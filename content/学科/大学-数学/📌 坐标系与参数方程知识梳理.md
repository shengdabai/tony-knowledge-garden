# 📌 坐标系与参数方程知识梳理

#### 🔹 坐标系基础
- **建立坐标系的条件**：任意一点需有确定坐标对应，反之依据坐标可确定点的位置
- **平面直角坐标系**：平面上任意一点P可由唯一有序实数对(x,y)确定
- **伸缩变换公式**：\[
\begin{cases}
x'=\lambda x (\lambda>0) \\
y'=\mu y (\mu>0)
\end{cases}
\]

#### 🔹 极坐标系
- **四要素**：极点、极轴、长度单位、角度单位及正方向（通常取逆时针）
- **点的极坐标**：有序数对(ρ,θ)，定义ρ≥0,0≤θ≤2π，z∈R
- **与直角坐标系互化前提**：极点与原点重合、极轴与x轴正半轴重合、单位长度相同
- **互化公式**：\[
\begin{cases}
x=\rho \cos\theta \\
y=\rho \sin\theta
\end{cases}
\quad \text{和} \quad
\begin{cases}
\rho^2=x^2+y^2 \\
\tan\theta=\frac{y}{x}(x\neq0)
\end{cases}
\]

#### 🔹 简单图形的极坐标方程

| **图形类型** | **方程形式** |
|--------------|--------------|
| 过极点、倾角为α的直线 | θ=α，θ=π+α |
| 不过极点、倾角为α的直线（d为距离） | ρsin(α-θ)=d |
| 过定点(ρ₀,θ₀)、倾角为α的直线 | ρsin(α-θ)=ρ₀sin(α-θ₀) |
| 圆的一般方程 | ρ²-2ρ₀ρcos(θ-θ₀)+ρ₀²-r²=0 |
| 圆心在(ρ₀,θ₀)的圆 | ρ=2rcos(θ-θ₀) |
| 圆心在x轴正半轴 | ρ=2rcosθ |
| 圆心在x轴负半轴 | ρ=-2rcosθ |
| 圆心在y轴正半轴 | ρ=2rsinθ |
| 圆心在y轴负半轴 | ρ=-2rsinθ |
| 以极点为圆心的圆 | ρ=r |

#### 🔹 参数方程
- **概念**：平面直角坐标系中，若曲线上任一点坐标(x,y)是某个变量的函数，且对于变量每个允许值，方程确定的点都在曲线上，则称\[
\begin{cases}
x=f(t) \\
y=g(t)
\end{cases}
\]为该曲线的参数方程

- **常见参数方程**：
  1. 圆x²+y²=r²：\[
\begin{cases}
x=r\cos\theta \\
y=r\sin\theta
\end{cases}
\]（θ为参数）
  2. 圆(x-x₀)²+(y-y₀)²=r²：\[
\begin{cases}
x=x₀+r\cos\theta \\
y=y₀+r\sin\theta
\end{cases}
\]（θ为参数）
  3. 椭圆$\frac{x²}{a²}+\frac{y²}{b²}=1$：\[
\begin{cases}
x=a\cos\theta \\
y=b\sin\theta
\end{cases}
\]（θ为参数）
  4. 双曲线$\frac{x²}{a²}-\frac{y²}{b²}=1$：\[
\begin{cases}
x=a\sec\theta \\
y=b\tan\theta
\end{cases}
\]（θ为参数）
  5. 抛物线y²=2px：\[
\begin{cases}
x=2pt² \\
y=2pt
\end{cases}
\]（t为参数）
  6. 过定点P(x₀,y₀)、倾角为θ的直线：\[
\begin{cases}
x=x₀+t\cos\theta \\
y=y₀+t\sin\theta
\end{cases}
\]（t为参数）

#### 🔹 特殊曲线参数方程
- **圆的渐开线**：以基圆圆心O为原点，直径所在直线为x轴建立坐标系，参数方程为\[
\begin{cases}
x=r(\cos\varphi+\varphi\sin\varphi) \\
y=r(\sin\varphi-\varphi\cos\varphi)
\end{cases}
\]（φ为参数）
- **圆的摆线**：根据摆线上动点运动轨迹，参数方程为\[
\begin{cases}
x=r(\varphi-\sin\varphi) \\
y=r(1-\cos\varphi)
\end{cases}
\]（φ为参数）

#### 🔹 学习误区
- 极坐标系中点与坐标不是一一对应，非极点坐标有无限多个
- 坐标互化时忽略原点不同需平移变换
- 圆的渐开线参数方程化为直角坐标方程为：$x\cos(\frac{1}{r}\sqrt{x²+y²}-r²)+y\sin(\sqrt{x²+y²}-r²)=r$
- 圆的摆线参数方程含反三角函数，直接用参数方程讨论性质更简便

#### 🔹 知能提升
- **坐标系作用**：刻画点的位置及变化，找到动点轨迹，通过数形结合解决几何问题
- **参数方程化普通方程方法**：代入消参法、加减消参法、平方和（差）消参法、整体消参法、三角恒等式消参法
- **直线参数方程应用**：过点P(x₀,y₀)的直线参数方程中，直线上一点Q(x,y)满足|PQ|=$\sqrt{a²+b²}|t|$
