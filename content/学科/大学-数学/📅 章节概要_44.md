# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **引入函数三大性质及应用场景**  
老师开场介绍函数在课本中有单调性、奇偶性、周期性三大性质，课本仅作定义解读与简单应用，而在竞赛和强基计划题目中，这些性质魅力尽显。老师准备通过几个题目，让学生领略函数三大性质的魅力，引出第一个题目：方程X方 + A cos X + 2 = 0只有一个解求A 。

[00:00:50](https://getnotes.seek:50) **利用函数奇偶性求解方程**  
老师指出这是个非常规方程，需用非常规方法。将方程看成函数F(X)=X方 + A cos X + 2，经分析得出F负X = FX，即函数为偶函数。由于偶函数图像关于Y轴对称，而此函数等于0只有一个解，所以这个解只能是0。把X = 0代入方程，得到0 + A cos 0 + 2 = 0，因cos 0 = 1，解得A = -2 ，展示了函数奇偶性在解题中的作用。

[00:02:38](https://getnotes.seek:158) **通过构造函数解决求值问题**  
老师给出题目3X + Y的5次方 + X5次方 + 4X + Y = 0，求4X + Y 。老师先对式子变形为3X + Y的5次方 + 3X + Y = -（X5次方 + X），然后构造函数FT = T的五次方 + T 。接着分析该函数既是奇函数，又通过导数可知是单调递增函数。利用奇函数性质将等式进一步变形，为后续解题奠定基础。

[00:04:26](https://getnotes.seek:266) **利用函数单调性得出结论**  
老师继续讲解，对于构造的函数FT ，因为它是奇函数，所以等式可化为F(3X + Y)=F(-X) 。但一般函数FA = FB不能推出A = B ，而此函数是单调递增函数，根据单调函数特性，FA = FB就能推出A = B ，所以3X + Y = -X ，进而得出4X + Y = 0 ，成功解决竞赛题，强调对函数性质透彻理解的重要性。

[00:07:59](https://getnotes.seek:479) **运用函数性质求多项式系数**  
老师给出强基计划题目，(1 + X + X方 + X3次方)(1 - X + X平方 - X3次方)的5次方展开式为A0 + a1X + a2X平方 + … + A30 X的30次方，要求求A19 。老师将其看成函数FX ，通过计算得出F负X = FX ，即函数为偶函数。又因它是多项式函数，根据多项式理论，偶函数的所有X奇次方系数全为0 ，所以A19 = 0 ，再次体现函数性质在解题中的强大作用。

[00:11:40](https://getnotes.seek:700) **总结函数性质的魅力**  
老师总结，通过这几个题目展示了函数三大性质的无穷魅力，表明深入理解函数性质，能让看似困难的数学题变得得心应手，引发学生对数学学习难度和痛苦程度的思考。
