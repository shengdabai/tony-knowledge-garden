# 📚 知识梳理

#### 🔍 比较实数的大小
- **依据**：\[a - b > 0 \Leftrightarrow a > b\]，\[a - b = 0 \Leftrightarrow a = b\]，\[a - b < 0 \Leftrightarrow a < b\]
- **方法**：求差法、求商法

#### ⚖️ 不等式的性质
1. **对称性**：\[a > b \Leftrightarrow b < a\]
2. **传递性**：\[a > b, b > c \Rightarrow a > c\]
3. **可加性**：\[a > b \Leftrightarrow a + c > b + c\]；\[a > b, c > d \Rightarrow a + c > b + d\]
4. **可乘性**：\[a > b, c > 0 \Rightarrow ac > bc\]；\[a > b, c < 0 \Rightarrow ac < bc\]
5. **乘方法则**：\[a > b > 0 \Rightarrow a^n > b^n\]（\(n \in \mathbf{N}\)且\(n > 1\)）
6. **开方法则**：\[a > b > 0 \Rightarrow \sqrt[n]{a} > \sqrt[n]{b}\]（\(n \in \mathbf{N}\)且\(n > 1\)）
