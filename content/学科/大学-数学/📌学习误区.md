# 📌学习误区

#### 🔍否定用语不能正确使用致误

| **原用语** | **否定用语** | **解释** |
| --- | --- | --- |
| 是 | 不是 | - |
| 有 | 没有 | - |
| 都是 | 不都是 | 即至少有一个不是 |
| 都有 | 不都有 | 即至少有一个没有 |
| 都不是 | 部分或全部是 | 即至少有一个是 |
| 至少有一个(是) | 全部不是 | - |
| 至少有一个不是 | 全部是 | - |
| 唯一 | 至少有两个 | - |

#### 🔍使用分析法时书写致误
- 未严格按格式书写，或未保证分析过程的每一步都是可逆推的。
