# 🎯 线性规划的有关概念

- **二元一次不等式表示的平面区域**：\(Ax+By+C>0\)在直角坐标系中表示直线\(Ax+By+C=0\)某一侧所有点组成的区域。
- **约束条件和目标函数**：
  - 约束条件：由\(\begin{cases} f_1(x,y) \geq 0 \\ f_2(x,y) \geq 0 \\ f_3(x,y) \geq 0 \end{cases}\)等线性不等式组成，称为线性约束条件。
  - 目标函数：设\(z=f(x,y)\)，若\(z\)是\(x,y\)的一次式，则称为**线性目标函数**。
- **线性规划问题**：求线性目标函数在线性约束条件下的最大值或最小值的问题，满足约束条件的解\((x,y)\)称为可行解，所有可行解组成的集合称为可行域，使目标函数取得最值的解称为最优解。
