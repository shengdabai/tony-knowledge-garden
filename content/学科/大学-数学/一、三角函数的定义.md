# 一、三角函数的定义

- 设角α终边上任意一点P(x,y)，点P到原点的距离为r（r>0），则：  
  - 正弦：`\[ \sin\alpha = \frac{y}{r} \]`  
  - 余弦：`\[ \cos\alpha = \frac{x}{r} \]`  
  - 正切：`\[ \tan\alpha = \frac{y}{x} \]`（x≠0）  
  - 余切：`\[ \cot\alpha = \frac{x}{y} \]`（y≠0）  
  - 正割：`\[ \sec\alpha = \frac{r}{x} \]`（x≠0）  
  - 余割：`\[ \csc\alpha = \frac{r}{y} \]`（y≠0）
