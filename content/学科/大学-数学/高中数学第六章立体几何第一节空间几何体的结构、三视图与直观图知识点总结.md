# 高中数学第六章立体几何第一节空间几何体的结构、三视图与直观图知识点总结

📌 **多面体的基本概念**  
- **面**：围成多面体的各个多边形  
- **棱**：两个面的公共边  
- **顶点**：棱和棱的公共点  
- **对角线**：连接不在同一面上的两个顶点的线段  
- **简单多面体**：表面经过连续变形可以变成球体的多面体，满足欧拉公式：\[V+F-E=2\]（\(V\)为顶点数，\(F\)为面数，\(E\)为棱数）  

📌 **多面体的分类**  
- **按面的性质**：  
  - **凸多面体**：将一个面伸展成平面，其余面都位于该平面同一侧  
  - **凹多面体**：不满足凸多面体条件的多面体  
- **按面数**：四面体（4个面）、五面体（5个面）等  
- **正多面体**：各面为全等正多边形且各顶点棱数相等，仅有5种：正四面体、正六面体、正八面体、正十二面体、正二十面体  

📌 **旋转体的结构**  
| 几何体 | 结构特征 |  
|--------|----------|  
| **棱柱** | 有两个面互相平行，其余各面都是四边形，且相邻四边形的公共边互相平行 |  
| **棱锥** | 有一个面是多边形，其余各面是有公共顶点的三角形 |  
| **棱台** | 用平行于棱锥底面的平面截棱锥，底面与截面之间的部分 |  
| **圆柱** | 以矩形的一边所在直线为轴旋转形成的旋转体 |  
| **圆锥** | 以直角三角形的一条直角边所在直线为轴旋转形成的旋转体 |  
| **圆台** | 用平行于圆锥底面的平面截圆锥，底面与截面之间的部分 |  
| **球** | 以半圆的直径所在直线为轴旋转形成的旋转体 |  

📌 **投影与三视图**  
- **投影的分类**：  
  - **中心投影**：投射线交于一点（如点光源），物体距离光源越近，投影越大  
  - **平行投影**：投射线平行，分为正投影（投射线垂直于投影面）和斜投影（投射线不垂直于投影面）  
- **三视图的定义**：  
  - **正视图**：光线从几何体前面向后面正投影  
  - **侧视图**：光线从几何体左面向右面正投影  
  - **俯视图**：光线从几何体上面向下面正投影  
- **三视图的规则**：  
  - 长对正（正视图与俯视图长度相等）  
  - 高平齐（正视图与侧视图高度相等）  
  - 宽相等（俯视图与侧视图宽度相等）  

📌 **直观图的画法**  
- **斜二测画法**：  
  1. 在已知图形中建立直角坐标系 \(Oxyz\)，画直观图时建立 \(O'x'y'z'\)，使 \(\angle x'O'y'=45^\circ\)，\(\angle x'O'z'=90^\circ\)  
  2. 平行于 \(x\) 轴、\(z\) 轴的线段在直观图中长度不变，平行于 \(y\) 轴的线段长度变为原来的一半  
  3. 被遮挡部分用虚线表示  

📌 **学习误区与注意事项**  
- 画三视图时易混淆正视图、侧视图、俯视图的方向，需明确投影方向  
- 简单组合体的三视图需分解为基本几何体后再绘制  
- 俯视图应理解为从物体正前方“从上往下”观察，而非直接俯视  
- 中心投影用于画实际效果图，平行投影用于立体几何作图
