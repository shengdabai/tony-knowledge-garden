# 二、导数的运算

#### 📌**常见初等函数的导数公式**

| 函数类型       | 导数公式                          |
|----------------|-----------------------------------|
| 常数函数       | \( (a)' = 0 \)（\( a \)为常数）   |
| 幂函数         | \( (x^n)' = nx^{n - 1} \)（\( n > 0 \)） |
| 正弦函数       | \( (\sin x)' = \cos x \)          |
| 余弦函数       | \( (\cos x)' = -\sin x \)         |
| 指数函数       | \( (a^x)' = a^x \ln a \)          |
| 自然指数函数   | \( (e^x)' = e^x \)                |
| 对数函数       | \( (\log_a x)' = \frac{1}{x \ln a} = \frac{\log_a e}{x} \) |
| 自然对数函数   | \( (\ln x)' = \frac{1}{x} \)       |

#### 📌**导数的运算法则**
- 和差法则：\( [f(x) \pm g(x)]' = f'(x) \pm g'(x) \)
- 乘法法则：\( [f(x)g(x)]' = f'(x)g(x) + f(x)g'(x) \)
- 除法法则：\( \left[ \frac{f(x)}{g(x)} \right]' = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2} \)

#### 📌**复合函数的导数**
- **概念**：由几个函数复合而成的函数。
- **求导法则**：复合函数\( y = f[\varphi(x)] \)对自变量\( x \)的导数\( y'_x \)，等于函数对中间变量\( u = \varphi(x) \)的导数\( y'_u \)乘以中间变量\( u \)对自变量\( x \)的导数\( u'_x \)，即\( y'_x = y'_u \cdot u'_x \)。
- **求导思路**：运用复合函数求导法则，将复合函数转化为基本函数的导数。
