# 💻 基本算法语句

#### 1. 赋值语句
- **格式**：变量名=表达式  
- **规则**：
  - 左边只能是变量名，不能是表达式（如：`2=x`错误，`x=5`正确）
  - 左右两边不能对换（如：`A+B=C`错误，`C=A+B`正确）
  - 不能用于代数式演算（如：`y=(x+1)(x-1)=x²-1`错误）
  - 赋值号与数学“=”意义不同（如：`N=N+1`表示更新变量N的值）

#### 2. 输入语句
- **格式**：`INPUT "提示内容"；变量`  
- **示例**：`INPUT "x="；x`  
- **功能**：实现算法输入

#### 3. 输出语句
- **格式**：`PRINT "提示内容"；表达式`  
- **示例**：`PRINT "S="；S`  
- **功能**：实现算法输出

#### 4. 条件语句
- **格式1（双分支）**：  
  ```
  IF 条件 THEN
      语句体1
  ELSE
      语句体2
  END IF
  ```
- **格式2（单分支）**：  
  ```
  IF 条件 THEN
      语句体
  END IF
  ```
- **功能**：处理条件分支逻辑结构

#### 5. 循环语句
- **当型循环（WHILE语句）**：  
  ```
  WHILE 条件
      循环体
  WEND
  ```
- **直到型循环（UNTIL语句）**：  
  ```
  DO
      循环体
  LOOP UNTIL 条件
  ```
- **功能**：实现算法中的循环结构
