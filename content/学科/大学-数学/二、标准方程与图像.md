# 二、标准方程与图像

| **标准方程**                | \(\frac{x^2}{a^2}-\frac{y^2}{b^2}=1(a>0,b>0)\) | \(\frac{y^2}{a^2}-\frac{x^2}{b^2}=1(a>0,b>0)\) |
|-----------------------------|------------------------------------------------|------------------------------------------------|
| **图形**                    | 焦点在\(x\)轴，左右两支                        | 焦点在\(y\)轴，上下两支                        |
| **焦点**                    | \((\pm c,0)\)                                  | \((0,\pm c)\)                                  |
| **顶点**                    | \((\pm a,0)\)                                  | \((0,\pm a)\)                                  |
| **范围**                    | \(|x|\geq a\)                                  | \(|y|\geq a\)                                  |
| **实轴长/虚轴长**           | \(2a\) / \(2b\)                                | \(2a\) / \(2b\)                                |
| **离心率**                  | \(e=\frac{c}{a}(e>1)\)，其中\(c^2=a^2+b^2\)     | \(e=\frac{c}{a}(e>1)\)，其中\(c^2=a^2+b^2\)     |
| **准线方程**                | \(x=\pm \frac{a^2}{c}\)                         | \(y=\pm \frac{a^2}{c}\)                         |
| **渐近线方程**              | \(y=\pm \frac{b}{a}x\)                          | \(y=\pm \frac{a}{b}x\)                          |
