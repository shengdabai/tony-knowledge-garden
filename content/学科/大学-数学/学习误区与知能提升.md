# 学习误区与知能提升

⚠️ **常见误区**  
- 忽视基本不等式成立的三个条件（“一正”“二定”“三相等”）  
- 等号不成立时，未改用单调性等其他方法求最值  
- 绝对值不等式去绝对值时忽略分类讨论  

📈 **拓展公式**  
- 乘方法则：若 \(a > b > 0\)，\(n\) 为正数，则 \(a^n > b^n\)  
- 平均数不等式链：\(\frac{n}{\frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_n}} \leq \sqrt[n]{a_1a_2\cdots a_n} \leq \frac{a_1 + a_2 + \cdots + a_n}{n} \leq \sqrt{\frac{a_1^2 + a_2^2 + \cdots + a_n^2}{n}}\)（\(a_i > 0\)）  

📈 **变形技巧**  
- 合理拆项或配组，使等号成立  
- 妙用“1”的代换（如 \(\frac{a}{b} + \frac{b}{a} \geq 2\)，\(a,b > 0\)）  
- 多个字母不等式可利用判别式法或参数分类讨论
