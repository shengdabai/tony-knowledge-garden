#### 内容总结
**通过不等式题目展示数形结合的魅力**
* **常规解法及局限**：对于不等式√(8 - 2x²) - x > -1，常规做法是将根号单独留下，变形为√(8 - 2x²) > x - 1 ，进而转化为不等式组{8 - 2x² ≥ 0 ，(8 - 2x²) > (x - 1)²}求解。这种做法虽能解题，但无法体现数学魅力，且面对题目变化时会一筹莫展，如将 -1 变为 A ，就需分段讨论，过程复杂。
* **构造函数与数形结合**：构造函数Y = √(8 - 2x²) ，变形可得x²/4 + Y²/8 = 1（Y≥0），其图像为半个椭圆；另一个函数Y = x - 1为直线。解不等式就变成判断椭圆在直线上方部分，通过解方程求出交点坐标，从而轻松解题。当 -1 变为 A 时，直线Y = x + A 成为平行直线系，通过分析直线与椭圆位置关系进行分段讨论：A < -2 ，有解； -2 < A < 2 ，有解； 2 < A < 2√3 ，有解； A ≥ 2√3 ，无解。
* **题目拓展与应用**：进一步拓展题目，若不等式解为空集，求A范围，从图可知A ≥ 2√3 ；若解为 -2 到 2 ，A ≤ -2 。将不等式变为方程√(8 - 2x²) = x + A ，若方程有解，即直线与椭圆有交点，A范围是[-2, 2√3] ；若方程只有一个解，A = 2√3 或 A ∈ (-2, 2) ；通过数形结合，这些复杂问题都能迎刃而解，体现了数形结合将复杂、抽象问题简单化、直观化的魅力，也是新高考强调的基本思想方法。
