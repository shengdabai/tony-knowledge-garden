# 🎯 知识梳理

#### 函数与方程的核心思想
- **方程思想**：将问题转化为对方程（组）的认识，通过解方程或对方程进行讨论使问题获得解决
- **函数思想**：用联系变化的观点分析问题，通过函数的形式把问题中的数量关系表示出来，运用函数的概念、图像、性质等对问题加以研究，使问题得以解决
- **等价关系**：方程\(f(x)=0\)有实解 ⟺ 函数\(y=f(x)\)与x轴有交点 ⟺ 函数\(y=f(x)\)有零点

#### 📌 函数的零点
- **定义**：使\(f(x)=0\)成立的实数x
- **存在性**：如图：\(f(a)f(b)<0\)，则\(f(x)\)至少存在一点\(c∈(a,b)\)，使\(f(c)=0\)
- **分类**：
  - 变号零点：函数图像与x轴相交
  - 不变号零点：函数图像与x轴相切
- **求法**：
  - 代数法：函数解析式是代数式，直接令式子等于零求方程的根
  - 几何法：函数解析式是超越式，依据定理，通过求端点值的符号找出零点位置，转化为两个容易作出函数图像的交点

#### 📊 常见函数模型及特点

| 模型类型 | 增长特点 |
|----------|----------|
| **直线模型** | 增长特点是直线上升的（\(k>0\)），通过图形可直观地认识到 |
| **指数函数模型** | 增长特点是随着自变量的增大，函数值增大的速度越来越快(底数\(a>1\))，常称为“指数爆炸” |
| **对数函数模型** | 增长特点是随着自变量的增大，函数值增大的速度越来越慢（底数\(a>1\)） |
| **幂函数模型** | 最常见的是二次函数 |

#### 🔍 解应用问题的一般步骤
1. 审题
2. 建模
3. 求解
4. 还原

#### 🔢 二分法求函数变号零点近似值的步骤
1. 确定区间\([a,b]\)，验证\(f(a)f(b)<0\)
2. 求区间\([a,b]\)的中点\(x_1\)
3. 计算\(f(x_1)\)：
   - 若\(f(x_1)=0\)，则\(x_1\)就是函数的零点
   - 若\(f(a)f(x_1)<0\)，则令\(b=x_1\) [此时零点\(x_0 ∈(a,x_1)\)]
   - 若\(f(b)f(x_1)<0\)，则令\(a=x_1\) [此时零点\(x_0 ∈(x_1,b)\)]
4. 判断是否达到精度\(ε\)：即若\(|a-b|<ε\)，则得到零点值\(x_1\)，或\(a\)，或\(b\)。否则重复2)-4)

#### 📝 求方程近似解的步骤
1. 首先要确定方程有几个根，可结合函数的单调性来判断
2. 其次确定根所在的大致区间，区间长度越小越好。一般控制在两个整数之间
3. 最后用二分法求解，当区间的两个端点的坐标差精确到要求的精确度时，这个近似值就是所求的近似解

#### ⚠️ 学习误区
- 构造函数研究方程、不等式问题时，所构造的函数图像不易画出致误
- 变形不等价导致失误
- 据图像回答问题或列式时出现错误
