# 一、知识梳理

#### 1. 三角函数模型的简单应用
- 由解析式作出图像，并研究性质  
- 由图像探求三角函数模型的解析式  
- 利用三角函数模型解决最值问题  
- 建立三角函数模型求临界值  

#### 2. 常见的最值问题类型

| **类型** | **表达式** | **求解方法** |  
|----------|------------|--------------|  
| 1 | \( y = a\sin x + b \)（或 \( a\cos x + b \)） | 利用函数的有界性，注意字母 \( a \) 符号的讨论 |  
| 2 | \( y = a\sin x + b\cos x + c \) | 辅助角公式转化为 \( y = \sqrt{a^2 + b^2}\sin(x+\varphi) + c \)，再用有界性求值域 |  
| 3 | \( y = a\sin^2 x + b\sin x + c \) | 配方后求二次函数的最值，注意 \( |\sin x| \leq 1 \) |  
| 4 | \( y = \frac{a\sin x + b}{c\sin x + d} \) | 反解出 \( \sin x \)，化归为 \( |\sin x| \leq 1 \) 解决 |  
| 5 | \( y = a(\sin x \pm \cos x) + b\sin x \cdot \cos x + c \) | 令 \( t = \sin x \pm \cos x \) 后转化为二次函数在闭区间上的最值问题 |
