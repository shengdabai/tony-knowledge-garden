# 🔍 椭圆的重要结论与公式

- **椭圆上的点到中心距离**：最小距离为短轴端点到中心的距离\(b\)，最大距离为长轴端点到中心的距离\(a\)。
- **椭圆上的点到焦点距离**：最大距离和最小距离的点均为长轴端点。
- **焦点三角形相关**：设椭圆的中心为\(O\)，焦点为\(F\)，\(D\)是短轴的一个端点，则\(|DF| = a\)，\(e = \cos\angle OFD\)。
- **焦点三角形面积公式**：\(S_{\triangle PF_1F_2} = \frac{1}{2}r_1r_2\sin\theta = b^2\tan\frac{\theta}{2} = c|y_p|\)（\(\theta = \angle F_1PF_2\)，\(r_1 = |PF_1|\)，\(r_2 = |PF_2|\)，\(P(x_p, y_p)\)为椭圆上一点）。
- **焦点三角形余弦公式**：\(\cos\theta = \frac{r_1^2 + r_2^2 - 4c^2}{2r_1r_2} = \frac{2b^2}{r_1r_2} - 1\)。
- **弦长公式**：\(|P_1P_2| = |x_1 - x_2|\sqrt{1 + k^2} = |y_1 - y_2|\sqrt{1 + \frac{1}{k^2}}\)（\(k\)为弦所在直线的斜率）。
- **焦准距**：\(\frac{a^2}{c} - c = \frac{b^2}{c}\)。
- **通径**：\(2ep = \frac{2b^2}{a}\)。
