# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **强调不等式重要性及学生对课本的忽视**  
讲师指出不等式在高考中占比重大，学生常因不等式出错。以在重点班授课为例，学生普遍找不到数学课本，对课本内容生疏，如问什么是基本不等式，几乎无人能答，反映出学生面对新高考对课本的不重视态度。讲师认为这种态度关键在于教师引导不足，好学生易轻视课本，而课本实则并不简单。  
[00:02:04](https://getnotes.seek:124) **基本不等式的概念讲解**  
讲师讲解基本不等式，数学上基本不等式为$\sqrt{AB} \leq \frac{A + B}{2}$（$A\geq0$，$B\geq0$） ，$\sqrt{AB}$是几何平均数，$\frac{A + B}{2}$是算术平均数，汉语言表述为两个正数几何平均数小于等于算术平均数。它是一切不等式的源头和基础。  
[00:02:56](https://getnotes.seek:176) **基本不等式的推导及相关不等式衍生**  
基本不等式源于数学三大著名非负数，由实数平方非负，即$(\sqrt{A} - \sqrt{B})^2 \geq 0$展开得到基本不等式。又从$(A - B)^2 \geq 0$推出$A^2 + B^2 \geq 2AB$，进一步得到$AB \leq \frac{A^2 + B^2}{2}$和$AB \leq (\frac{A + B}{2})^2$ ，并探讨了$(\frac{A + B}{2})^2$与$\frac{A^2 + B^2}{2}$的大小关系。  
[00:05:20](https://getnotes.seek:320) **阐述基本不等式的魅力**  
基本不等式实现了无理到有理、相乘到相加的转变，像“降维打击”般神奇。在整个不等式体系中，数的相乘、相加、平方相加之间可相互转换，凸显其重要地位。  
[00:06:56](https://getnotes.seek:416) **基本不等式在高考题中的应用实例**  
讲师提到一道高考题由课本习题演变而来，融合基本不等式与对数运算法则，求函数最大值，但正确率低。通过对数运算法则和换底公式变形，统一底数，当式子出现两数相乘且相加为常数时，利用基本不等式得出函数小于等于0，从而求出最大值为0 。
