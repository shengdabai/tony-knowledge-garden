# 四、对称性

| 对称类型   | 条件表达式                                                                 | 对称轴/中心               |
|------------|--------------------------------------------------------------------------|---------------------------|
| 轴对称     | $f(a+x) = f(a-x)$ 或 $f(2a-x) = f(x)$                                    | $x = a$                   |
| 轴对称     | $f(a+x) = f(b-x)$                                                        | $x = \frac{a+b}{2}$       |
| 中心对称   | $f(a+x) = -f(a-x)$ 或 $f(2a-x) = -f(x)$                                  | $(a, 0)$                  |
| 中心对称   | $f(a+x) = 2b - f(a-x)$                                                   | $(a, b)$                  |
