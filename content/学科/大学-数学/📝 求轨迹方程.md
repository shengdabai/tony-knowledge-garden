# 📝 求轨迹方程

#### 📌 **如何建系**

| 已知条件                | 建系方法                                                                 |
|-------------------------|--------------------------------------------------------------------------|
| 一个定点                | 以该定点为坐标原点                                                      |
| 两个定点                | 以两定点的中点为原点，两定点所在直线为坐标轴                            |
| 两条互相垂直的直线      | 以它们为坐标轴建立直角坐标系                                            |
| 一定点和一条定直线      | 以定点到定直线的垂线段的中点为原点，以点到直线的垂线为\( x \)轴          |
| 定角                    | 以定角的顶点为原点，定角的角平分线为\( x \)轴                            |

#### 📌 **求轨迹方程的常用方法**
- **直接法**：直接根据已知条件列出动点坐标满足的方程  
- **定义法**：若动点运动的几何条件恰好与某圆锥曲线的定义吻合，可直接根据定义建立轨迹方程  
- **代入法**：当所求轨迹上的动点\( P \)随着曲线\( f(x,y)=0 \)上的动点\( Q \)的变动而变动，且\( Q \)的坐标\( (x_0,y_0) \)可用\( P \)的坐标\( (x,y) \)表示，则将结果代入\( f(x_0,y_0)=0 \)化简  
- **参数法**：选取与动点坐标相关的量（如角、斜率）为参数，建立参数方程后消参  
- **交轨法**：联立两条动曲线方程，消去参数得到动点轨迹方程（属于参数法的特殊形式）  
- **待定系数法**：先确定曲线类型与方程结构，再用待定系数求解（最基本方法）
