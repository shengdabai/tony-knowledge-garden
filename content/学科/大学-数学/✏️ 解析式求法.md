# ✏️ 解析式求法

| 方法 | 适用场景 |
|------|----------|
| **代入法** | 已知\( f(x) \)，求\( f[g(x)] \)解析式 |
| **待定系数法** | 已知函数类型（如一次函数、二次函数） |
| **配凑法** | 已知\( f[g(x)] \)解析式，需从表达式中拼凑出\( g(x) \) |
| **换元法** | 已知\( f[g(x)] \)表达式，通过换元简化求解 |
| **方程组法** | 已知\( f(x) \)与\( f[g(x)] \)的关系式，联立方程求解 |
| **特殊值法** | 通过代入特殊值找规律，简化问题 |
> ⚠️ 注意：求解析式时必须注明定义域
