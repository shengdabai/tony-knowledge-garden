# 高中数学第七章数列第二节等差数列知识点总结

📚 **等差数列知识梳理**  
- **定义**：一个数列从第二项起，每一项与它的前一项的差都等于同一个常数，这个数列叫做等差数列，常数称为公差（用\(d\)表示）。  
  - 数学表达：\(a_{n+1}-a_n=d, n\in\mathbb{N}^*\) 或 \(a_n - a_{n-1}=d, n\geq2, n\in\mathbb{N}^*\)  

- **通项公式**  
  - 基本公式：\(a_n = a_1 + (n-1)d\)  
  - 推广变形：\(a_n = a_m + (n-m)d\) 或 \(d = \frac{a_n - a_m}{n - m}\)  

- **前\(n\)项和公式**  
  - 公式：\(S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d\)  
  - 推导方法：倒序相加法  

🎯 **等差数列判定方法**  
| 方法名称       | 数学表达式                                                                 |
|----------------|--------------------------------------------------------------------------|
| 定义法         | \(a_n - a_{n-1} = d\)（\(n\geq2\)，\(d\)为常数）                          |
| 等差中项法     | \(2a_n = a_{n+1} + a_{n-1}\)（\(n\geq2\)）                                 |
| 通项公式法     | \(a_n = An + B\)（\(A,B\in\mathbb{R}\)，\(A=d\)，\(B=a_1 - d\)）           |
| 前\(n\)项和法  | \(S_n = An^2 + Bn\)（\(A,B\in\mathbb{R}\)，\(A=\frac{d}{2}\)，\(B=a_1 - \frac{d}{2}\)） |

✨ **等差数列性质**  
- **单调性**：\(d>0\)时为递增数列；\(d<0\)时为递减数列；\(d=0\)时为常数列。  
- **等差中项**：若三个数\(a,A,b\)成等差数列，则\(A\)是\(a\)与\(b\)的等差中项，即\(A = \frac{a+b}{2}\)。  
- **前\(n\)项和性质**：  
  - 若\(S_n\)是等差数列\(\{a_n\}\)的前\(n\)项和，则\(\{\frac{S_n}{n}\}\)也是等差数列。  
  - 项数为\(2n-1\)时：\(S_{2n-1}=(2n-1)a_n\)，\(S_奇 - S_偶 = a_n\)，\(\frac{S_奇}{S_偶} = \frac{n}{n-1}\)（\(a_n\)为中间项）。  
  - 项数为\(2n\)时：\(S_{2n}=n(a_1 + a_{2n}) = n(a_n + a_{n+1})\)，\(S_偶 - S_奇 = nd\)，\(\frac{S_偶}{S_奇} = \frac{a_n}{a_{n-1}}\)。  
- **子数列性质**：等差数列中依次\(k\)项的和（\(S_{2k}-S_k, S_{3k}-S_{2k},\cdots\)）仍成等差数列，公差为\(k^2d\)。  
- **运算性质**：若\(\{a_n\}\)、\(\{b_n\}\)是等差数列，则\(\{ma_n + kb_n\}\)（\(m,k\)为常数）也是等差数列。  
- **对称性**：若\(m+n=p+q\)，则\(a_m + a_n = a_p + a_q\)。  

⚠️ **学习误区与知能提升**  
- **\(a_n\)与\(S_n\)关系**：利用\(a_n = S_n - S_{n-1}\)时需注意\(n\geq2\)，需验证\(n=1\)时是否成立，否则表示为分段函数：  
  \[
  a_n = \begin{cases} 
  S_1, & n=1 \\
  S_n - S_{n-1}, & n\geq2 
  \end{cases}
  \]  
- **递推公式求通项**：形如\(\begin{cases} a_1 = a \\ a_{n+1} = pa_n + q \end{cases}\)（\(p,q\neq0\)），可变形为\(\frac{a_{n+1}}{p^{n+1}} = \frac{a_n}{p^n} + \frac{q}{p^{n+1}}\)，令\(b_n = \frac{a_n}{p^n}\)，转化为\(b_{n+1} = b_n + g(n)\)后用累加法求解。  

📝 **学法指导**  
- **对称性设未知数**：三个数成等差数列可设为\(a-d, a, a+d\)；四个数成等差数列可设为\(a-3d, a-d, a+d, a+3d\)。  
- **基本量思想**：涉及\(a_1, n, d, S_n, a_n\)五个量时，已知三个可求另外两个。
