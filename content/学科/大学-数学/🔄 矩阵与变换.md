# 🔄 矩阵与变换

#### 1. 点的变换
- **定义**：设$P(x,y)$为原坐标，$P'(x',y')$为变换后的坐标，$k≠0$，则$\begin{bmatrix} x'\\y' \end{bmatrix}=\begin{bmatrix} a&b\\c&d \end{bmatrix}\begin{bmatrix} x\\y \end{bmatrix}=\begin{bmatrix} ax+by\\cx+dy \end{bmatrix}$，即$\begin{cases} x'=ax+by \\ y'=cx+dy \end{cases}$

#### 2. 常见的矩阵变换

| 变换类型       | 变换公式                                                                 | 对应矩阵表示                          |
|----------------|--------------------------------------------------------------------------|---------------------------------------|
| **旋转变换**   | 以原点为中心，旋转角为$\varphi$：$\begin{cases} x'=x\cos\varphi - y\sin\varphi \\ y'=x\sin\varphi + y\cos\varphi \end{cases}$ | $\begin{bmatrix} \cos\varphi & -\sin\varphi \\\sin\varphi & \cos\varphi \end{bmatrix}$ |
| **反射变换**   | x轴对称：$\begin{cases} x'=x \\ y'=-y \end{cases}$                        | $\begin{bmatrix} 1&0 \\ 0&-1 \end{bmatrix}$ |
|                | y轴对称：$\begin{cases} x'=-x \\ y'=y \end{cases}$                        | $\begin{bmatrix} -1&0 \\ 0&1 \end{bmatrix}$ |
|                | y=x对称：$\begin{cases} x'=y \\ y'=x \end{cases}$                          | $\begin{bmatrix} 0&1 \\ 1&0 \end{bmatrix}$ |
|                | 原点对称：$\begin{cases} x'=-x \\ y'=-y \end{cases}$                      | $\begin{bmatrix} -1&0 \\ 0&-1 \end{bmatrix}$ |
| **伸缩变换**   | 横坐标变为原来的$k$倍，纵坐标不变：$\begin{cases} x'=kx \\ y'=y \end{cases}$ | $\begin{bmatrix} k&0 \\ 0&1 \end{bmatrix}$ |
|                | 纵坐标变为原来的$k$倍，横坐标不变：$\begin{cases} x'=x \\ y'=ky \end{cases}$ | $\begin{bmatrix} 1&0 \\ 0&k \end{bmatrix}$ |
|                | 横纵坐标分别变为原来的$k_1,k_2$倍：$\begin{cases} x'=k_1x \\ y'=k_2y \end{cases}$ | $\begin{bmatrix} k_1&0 \\ 0&k_2 \end{bmatrix}$ |
| **投影变换**   | 关于x轴的正投影：$\begin{cases} x'=x \\ y'=0 \end{cases}$                  | $\begin{bmatrix} 1&0 \\ 0&0 \end{bmatrix}$ |
|                | 关于y轴的正投影：$\begin{cases} x'=0 \\ y'=y \end{cases}$                  | $\begin{bmatrix} 0&0 \\ 0&1 \end{bmatrix}$ |
| **切变变换**   | 平行于x轴：$\begin{cases} x'=x+ky \\ y'=y \end{cases}$                     | $\begin{bmatrix} 1&k \\ 0&1 \end{bmatrix}$ |
|                | 平行于y轴：$\begin{cases} x'=x \\ y'=kx+y \end{cases}$                     | $\begin{bmatrix} 1&0 \\ k&1 \end{bmatrix}$ |

#### 3. 变换性质
- 投影变换是映射，但不是一一映射  
- 在伸缩变换之下，直线仍然变为直线，线段仍然变为线段  
- 切变变换性质：（1）x轴上的点是不动点；（2）保持图形面积大小不变，点间的距离和夹角大小可以改变且点的运动是沿坐标轴方向进行的，其实质是横（纵）坐标成比例地运动
