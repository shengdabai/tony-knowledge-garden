# 💡 利用导数判断函数单调性的应用

- 证明不等式：\( f(x) \geq g(x), x \in (a,b) \)，转化为证\( f(x) - g(x) > 0 \)。若\( (f(x) - g(x))' > 0 \)，\( f(x) - g(x) \)在\( (a,b) \)上单调递增，只要\( f(a) - g(a) > 0 \)即可；若\( (f(x) - g(x))' < 0 \)，\( f(x) - g(x) \)在\( (a,b) \)上单调递减，只要\( f(b) - g(b) > 0 \)即可。
- 研究方程根的个数：运用数形结合思想确定函数图像与\( x \)轴的交点个数。
- 求函数的值域。
- 求参数的值（取值范围）：令\( f'(x) \geq 0 \)（或\( \leq 0 \)）求出参数，已知单调性求参数范围，检验参数，去除\( f'(x) \)恒为0的值。
