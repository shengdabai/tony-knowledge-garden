# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **通过题目引入消元问题**  

讲座开始，讲师提出一个在数学上具有重要地位的函数\(Y=\frac{Mx^{2}+4\sqrt{3}x + N}{x^{2}+1}\)，该函数形式复杂，包含分式、二次项以及\(M\)、\(N\)两个参数，已知其最大值为\(7\)，最小值为\(-1\)，要求\(MN\)的值。讲师强调在解决此类多变量问题时，要明确求谁就留下谁，本题需保留\(M\)、\(N\)，消去\(x\)、\(y\)，引出消元的主题。  

[00:01:21](https://getnotes.seek:81) **确定消元策略**  

讲师指出\(x\)、\(y\)、\(M\)、\(N\)四个变量同时存在难以求解，所以要逐个消元，先消去\(x\)。讲师用“上帝让谁死亡，先让谁疯狂”这一形象的表述，说明消元思路，即让要消去的变量在式子中占据主导地位，为后续操作做铺垫。  

[00:02:07](https://getnotes.seek:127) **消去\(x\)的具体操作**  

讲师以“让\(x\)疯狂”为指引，将函数进行变形，把分母乘过来得到\((Y - M)x^{2}-4\sqrt{3}x + Y - N = 0\)，成功构造出关于\(x\)的一元二次方程。因为\(x\)能取任意实数，所以该方程必然有解，根据方程有解的性质，得出判别式\(\Delta\geq0\)，即\(48 - 4(Y - M)(Y - N)\geq0\)，从而利用判别式消去了\(x\)，此时式子中只剩下\(Y\)、\(M\)、\(N\)三个变量。  

[00:04:05](https://getnotes.seek:245) **准备消去\(Y\)**  

在消去\(x\)后，讲师提出下一步要消去\(Y\)，同样运用“让\(Y\)疯狂”的思路，将关于\(Y\)的不等式重新整理为\(Y^{2}-(M + N)Y + MN - 12\leq0\)，使\(Y\)成为主角，为利用函数\(Y\)的最值条件消去\(Y\)做准备。  

[00:05:12](https://getnotes.seek:312) **利用函数最值消去\(Y\)并求解\(M\)、\(N\)**  

讲师结合函数\(Y\)最大值为\(7\)，最小值为\(-1\)且函数连续的条件，得出\(Y^{2}-(M + N)Y + MN - 12 = 0\)的解为\(7\)和\(-1\)。然后依据韦达定理，两根之和等于\(-\frac{b}{a}\)，两根之积等于\(\frac{c}{a}\)，得到关于\(M\)、\(N\)的两个方程，通过联立这两个方程组成方程组，就可以求解出\(M\)、\(N\)的值，至此完成整个题目的解题思路讲解。  

[00:06:16](https://getnotes.seek:376) **总结消元方法**  

讲师回顾整个解题过程，强调当数学问题中出现多个变量时，消元是重要技巧，要逐个消灭变量，牢记求谁留谁的原则，消元过程中通过让要消去的变量在式子中占据主导地位来实现消元，再次阐述“上帝让谁死亡，先让谁疯狂”所体现的数学消元智慧。
