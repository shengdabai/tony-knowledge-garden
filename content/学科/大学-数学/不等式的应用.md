# 不等式的应用

📊 **求最值问题**  
- **和定积最大**：若 \(x + y = S\)（定值），则 \(xy \leq \frac{S^2}{4}\)（当且仅当 \(x = y\) 时取等号）  
- **积定和最小**：若 \(xy = P\)（定值），则 \(x + y \geq 2\sqrt{P}\)（当且仅当 \(x = y\) 时取等号）  
- **使用条件**：满足“一正”（变量为正）、“二定”（和或积为定值）、“三相等”（等号成立条件）  

📊 **解不等式应用的主要步骤**  
1. **审题**：必要时画出示意图，明确已知条件与目标  
2. **建模**：建立不等式模型，转化文字、图形、符号语言  
3. **求解**：利用不等式性质或定理求解  
4. **验证**：检查等号成立条件及实际意义
