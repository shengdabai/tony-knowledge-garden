# 📚 函数的单调性与导数

#### 🔍 单调性的判断
- 设函数\( f(x) \)在某个区间\( (a,b) \)内可导：
  - 若\( f'(x) > 0 \)，则函数\( y = f(x) \)在\( (a,b) \)单调递增；
  - 若\( f'(x) < 0 \)，则函数\( y = f(x) \)在\( (a,b) \)单调递减；
  - 若在\( (a,b) \)内\( f'(x) = 0 \)，则\( y = f(x) \)在\( (a,b) \)内是常数。

#### 📝 求单调区间步骤
1. 求\( f(x) \)的定义域；
2. 求出\( f'(x) \)；
3. 令\( f'(x) = 0 \)，求方程所有的根（又称驻点）；
4. 据驻点在定义域内区间，列表考察所划区间内\( f'(x) \)的符号，依“正则增，负则减”确定单调区间。

#### ⚠️ 学习误区
- 在某区间上单调增或减的函数没有极值；
- \( f'(x) > 0 \)是\( f(x) \)在对应区间是增函数的充分非必要条件；\( f'(x) < 0 \)是\( f(x) \)在对应区间是减函数的充分非必要条件；
- 求单调区间易忘定义域，它是定义域的子区间。
