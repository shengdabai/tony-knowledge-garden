📌 **进位制**  
- **概念**：为了计数和运算方便而约定的计数系统  
- **k进制特点**：具有k个数字符号（0,1,2,...,k-1），由低位到高位按"满k进一"规则计数（k>1且k∈Z）  
- **k进制表示**：\(a_n a_{n-1} \cdots a_1 a_0\)（其中\(0 < a_n < k\)，\(0 \leq a_{n-1},\cdots,a_1,a_0 < k\)）  

🔄 **进位制转化方法**  
| 转化类型               | 步骤                                                                 |
|------------------------|----------------------------------------------------------------------|
| k进制→十进制           | 先将k进制数写成各位数字与k的幂的乘积形式，再按十进制运算规则计算结果 |
| 十进制→k进制           | 用k连续去除十进制数或所有商，直到商为0，将余数倒序写出               |
| k进制之间转化          | 先转化为十进制，再转化为目标k进制                                   |

📝 **辗转相除法（求最大公约数）**  
- **思想**：用较大数除以较小数，所得余数和较小数构成新数对，重复运算至余数为0，此时较小数即为最大公约数  
- **算法步骤**：  
  1. 输入两个正整数m、n（m>n）  
  2. 计算\(r = m \mod n\)，将r赋值给v  
  3. 若r≠0，则m=n，n=r，返回步骤2；若r=0，执行步骤4  
  4. 输出最大公约数n  

📜 **更相减损法（求最大公约数）**  
- **来历**：出自《九章算术》"更相减损术"："可半者半之，不可半者，副置分母、子之数，以少减多，更相减损，求其等也，以等数约之。"  
- **现代语言步骤**：  
  1. 若两数都是偶数，用2约简；否则执行步骤2  
  2. 以较大数减较小数，差与较小数比较，重复大数减小数操作，直到两数相等，该数（或与约简数的乘积）即为最大公约数  

🧮 **秦九韶算法（多项式求值）**  
- **定义**：将n次多项式求值转化为n个一次多项式求值的问题  
- **递推公式**：  
  \[
  v_0 = a_n
  \]
  \[
  v_k = v_{k-1}x + a_{n-k} \quad (k=1,2,\cdots,n)
  \]
- **算法步骤**：  
  1. 输入多项式次数n、最高次项系数\(a_n\)和x值  
  2. 初始化\(v = a_n\)，\(i = n-1\)  
  3. 输入i次项系数\(a_i\)，计算\(v = vx + a_i\)，\(i = i-1\)  
  4. 若i≥0，返回步骤3；否则输出v  

⚠️ **学习误区**  
- 进位制转化时识图不清或步骤混淆  
- 秦九韶算法计算多项式值时，未能正确改写多项式表达式  
- 混淆辗转相除法与更相减损法的计算方法（前者以除法为主，次数较少；后者以减法为主，次数较多）
