# 一、柱体、锥体、台体的体积公式

- **柱体**：  
  - 通用公式：\( V_{\text{柱体}} = Sh \)（\( S \)为底面积，\( h \)为高）  
  - 圆柱：\( V_{\text{圆柱}} = \pi r^2 h \)（\( r \)为底面半径）  

- **锥体**：  
  - 通用公式：\( V_{\text{锥体}} = \frac{1}{3}Sh \)  

- **台体**：  
  - 通用公式：\( V_{\text{台体}} = \frac{1}{3}h(S + \sqrt{SS'} + S') \)（\( S, S' \)为上下底面积）  
  - 圆台：\( V_{\text{圆台}} = \frac{1}{3}\pi h(r^2 + rr' + r'^2) \)（\( r, r' \)为上下底面半径）
