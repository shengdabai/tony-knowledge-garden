# 六、三角函数线

- **定义**：单位圆中，有向线段MP（正弦线）、OM（余弦线）、AT（正切线）分别表示sinα、cosα、tanα  
- **注意事项**：  
  - 方向与坐标轴一致为正，相反为负  
  - 角α终边在x轴上时，正切线、正弦线缩为点；在y轴上时，余弦线缩为点，正切线不存在  
  - 若`\[ 0 < \alpha < \frac{\pi}{2} \]`，则`\[ \sin\alpha < \tan\alpha \]`且`\[ \sin\alpha + \cos\alpha > 1 \]`
