# 📅 章节概要

[00:00:00](https://getnotes.seek:0) **二分法的引入 - 图书馆找未打标签书案例**  
讲师开场介绍要讲所有算法的基石二分法，以在图书馆带8本书过安检，其中一本未打标签需找出为例。常规做法是一本本排查需8次，而数学家（讲师假设身份）提出用二分法，只需3次。具体操作是先将8本书分成两堆，每次抱着4本过安检，若这4本安检没响则安全，若响了则未打标签的书在这4本中，再将这4本分成两堆，每次抱2本，重复上述判断，最后再将有问题的2本分开抱，最多3次就能找到未打标签的书，其理论依据是log₂8 = 3 。讲师指出二分法在计算机和优化算法中经常出现。

[00:02:38](https://getnotes.seek:158) **二分法的趣味思考 - 安检笑话及概率分析**  
讲师讲了一个关于二分法找未打标签书的笑话，每次抱着含未打标签书的一堆书过安检，安检都响，结果还没找出书就被安检拦住。随后分析这种每次都选中含未打标签书那堆的概率为1/8 。讲完笑话后，讲师准备引入更复杂案例，引导听众思考。

[00:03:45](https://getnotes.seek:225) **三分法的引出 - 9个球找重球问题**  
讲师给出9个完全相同球中有一个重球，利用天平称重找出重球的问题，让听众思考需称多少次。部分听众提出用二分法，每边放4个球，可能需3 - 4次。讲师肯定其运用二分法思维，但指出只需2次就能找出重球，关键在于天平称重结果有三种（左重、右重、一样重），与安检门响或不响的二分属性不同，是三分属性，这是破题关键。

[00:05:56](https://getnotes.seek:356) **三分法的原理及步骤 - 9球问题详解**  
讲师进一步解释三分法原理，以3个球找重球为例，将其中2个球放天平上，若一样重，重球就是剩下那个；若不一样重，可直接判断出重球。因为天平能提供三个读数，所以称一次就能找出3个球中的重球。对于9个球，可分成三堆，利用天平的三分读数，若两堆一样重，重球在第三堆，若不一样重，可确定重球在哪一堆，之后再对有重球的那堆用同样方法，所以只需两次就能找出9个球中的重球，对应公式为log₃N ，9个球即log₃9 = 2次，同时对比了二分法和三分法的分差图。

[00:09:22](https://getnotes.seek:562) **9球问题进阶 - 不知球轻重及是否有坏球**  
讲师对9球问题进行进阶，此时不知9个球中是否有坏球，也不知坏球是轻是重，仍用天平称重，问需称多少次能找出坏球、判断其轻重。讲师给出答案是3次，先将球分成三组（A、B、C组各3个球），通过AB比较、BC比较，可判断是否有坏球以及坏球轻重，之后再按已知坏球轻重的方法找出坏球。同时提到不同条件下三次称重可分辨球的数量，知道球偏重或偏轻可分辨27个球，不知球偏轻偏重且不确定是否有坏球最多可分辨12个球。

[00:12:33](https://getnotes.seek:753) **12球找重球问题 - 更复杂的分组与判断**  
讲师给出12个球中有一个重球，问最少需称多少次找到。答案是3次，第一步将12个球分成三组，每组4个，通过第一次称重可锁定重球所在的4个球组。第二次称重时，因4个球不能很好适配天平的三分信息，所以选其中3个球，一边放1个，一边放1个，另1个放旁边，若天平不平衡可直接找出重球，若平衡则需对剩下2个球再比较一次，由此算出总共需称三次。

[00:14:39](https://getnotes.seek:879) **从具体问题到通用理论 - 基于尝试次数的球数计算**  
讲师从9个球、12个球的问题推出通用理论，若有K次尝试机会，已知球重或轻，最多可处理3的K次方个球；若不知球重或轻，最多可处理(3ᴷ - 1)/2个球；若既不知球重或轻，又不确定是否有坏球，最多可处理(3ᴷ - 3)/2个球。讲师强调此理论在实际场景如质量检查、故障检查中的重要应用，在这些场景中，知道物品更多信息，就能用更少次数检测出问题物品。
