# 📌 知识梳理

#### 不等式的性质
- **均值定理**  
  对于正数\(a_1,a_2,...,a_n\)，有：  
  \[\frac{2}{\frac{1}{a_1}+\frac{1}{a_2}} \leq \sqrt{a_1a_2} \leq \frac{a_1+a_2}{2} \leq \sqrt{\frac{a_1^2+a_2^2}{2}}\]  
  推广至n元形式：  
  \[\frac{n}{\frac{1}{a_1}+\frac{1}{a_2}+...+\frac{1}{a_n}} \leq \sqrt[n]{a_1a_2...a_n} \leq \frac{a_1+a_2+...+a_n}{n} \leq \sqrt{\frac{a_1^2+a_2^2+...+a_n^2}{n}}\]

- **绝对值不等式**  
  - **定义**：\[|x|= \begin{cases} x & (x \geq 0) \\ -x & (x < 0) \end{cases}\]  
  - **解法**：  
    \(|x| < a\ (a>0) \Leftrightarrow -a < x < a\)  
    \(|x| > a\ (a>0) \Leftrightarrow x < -a\) 或 \(x > a\)  
  - **性质**：\[||a| - |b|| \leq |a \pm b| \leq |a| + |b|\]

- **排序不等式**  
  设\(a_1 \leq a_2 \leq ... \leq a_n\)，\(b_1 \leq b_2 \leq ... \leq b_n\)，\(c_1,c_2,...,c_n\)是\(b_1,b_2,...,b_n\)的任意排列，则：  
  \[a_1b_n + a_2b_{n-1} + ... + a_nb_1 \leq a_1c_1 + a_2c_2 + ... + a_nc_n \leq a_1b_1 + a_2b_2 + ... + a_nb_n\]  
  （反序和 ≤ 乱序和 ≤ 顺序和，当且仅当\(a_1=a_2=...=a_n\)或\(b_1=b_2=...=b_n\)时等号成立）

- **柯西不等式**  
  - **代数形式**：\((a_1b_1 + a_2b_2)^2 \leq (a_1^2 + a_2^2)(b_1^2 + b_2^2)\)（等号成立当且仅当\(a_1b_2 = a_2b_1\)）  
  - **向量形式**：\(| \boldsymbol{a} \cdot \boldsymbol{b} | \leq |\boldsymbol{a}| \cdot |\boldsymbol{b}|\)（等号成立当且仅当\(\boldsymbol{a} = \boldsymbol{b}\)）  
  - **一般形式**：对任意实数\(a_i,b_i\)，有\((\sum_{i=1}^n a_ib_i)^2 \leq (\sum_{i=1}^n a_i^2)(\sum_{i=1}^n b_i^2)\)

- **贝努利不等式**  
  \[(1+x)^n > 1+nx\]（其中\(x > -1, x \neq 0, n \geq 1, n \in \mathbb{N}\)）
