# 知识梳理

📌 **均值定理**  
- 核心公式：对于 \(a,b>0\)，有 \(\frac{2}{\frac{1}{a}+\frac{1}{b}} \leq \sqrt{ab} \leq \frac{a+b}{2} \leq \sqrt{\frac{a^2+b^2}{2}}\)  
- 基础变形：\(a^2 + b^2 \geq 2ab\)（当且仅当 \(a=b\) 时取等号）  

📌 **绝对值不等式的性质**  
- 定义：\(|x| = \begin{cases} x & (x \geq 0) \\ -x & (x < 0) \end{cases}\)  
- 解集规则：  
  - \(|x| > a \Leftrightarrow x < -a\) 或 \(x > a\)（\(a > 0\)）  
  - \(|x| < a \Leftrightarrow -a < x < a\)（\(a > 0\)）  
- 三角不等式：\(||a| - |b|| \leq |a \pm b| \leq |a| + |b|\)
