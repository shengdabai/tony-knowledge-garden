# 📈 特征值与特征向量

#### 1. 定义
- 设$A=\begin{bmatrix} a&b\\c&d \end{bmatrix}$，存在非零向量$\alpha=\begin{bmatrix} x\\y \end{bmatrix}$满足$A\alpha=\lambda\alpha$，称$\lambda$为$A$的一个特征值，$\alpha$叫特征向量  
- $f(\lambda)=\begin{vmatrix} \lambda -a&-b\\-c&\lambda -d \end{vmatrix}$称为特征多项式

#### 2. 求解步骤
1. 写出矩阵$A$的特征矩阵$\begin{bmatrix} \lambda -a&-b\\-c&\lambda -d \end{bmatrix}$及特征多项式$f(\lambda)=\begin{vmatrix} \lambda -a&-b\\-c&\lambda -d \end{vmatrix}=\lambda^2-(a+d)\lambda+ad-bc$  
2. 令$f(\lambda)=0$，解特征方程$f(\lambda)=0$，得特征根$\lambda=\lambda_1$或$\lambda=\lambda_2$  
3. 将$\lambda$代入齐次方程组$\begin{cases} (\lambda -a)x - by=0 \\ -cx + (\lambda -d)y=0 \end{cases}$，写出一组解，即为对应特征值的特征向量  

#### 3. 求$M^n\beta$的步骤
1. 求$M$的特征值$\lambda_1,\lambda_2$和特征向量$\alpha_1,\alpha_2$  
2. 用特征向量$\alpha_1,\alpha_2$线性表示向量$\beta=\begin{bmatrix} x\\y \end{bmatrix}$，即$\beta=m\alpha_1+n\alpha_2$（$m,n$是常数）  
3. 代入$M\beta=M(m\alpha_1+n\alpha_2)=mM\alpha_1+nM\alpha_2=m\lambda_1\alpha_1+n\lambda_2\alpha_2$  
4. $M^n\beta=m\lambda_1^n\alpha_1+n\lambda_2^n\alpha_2$
