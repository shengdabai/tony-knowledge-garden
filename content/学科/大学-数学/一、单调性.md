# 一、单调性

**定义**  
- 增函数：$\forall x_1 < x_2 \in A$，有$f(x_1) < f(x_2)$  
- 减函数：$\forall x_1 < x_2 \in A$，有$f(x_1) > f(x_2)$  

**数学表达**  
- 单调递增：$\frac{f(x_1)-f(x_2)}{x_1-x_2} > 0 \Leftrightarrow (x_1-x_2)[f(x_1)-f(x_2)] > 0$  
- 单调递减：$\frac{f(x_1)-f(x_2)}{x_1-x_2} < 0 \Leftrightarrow (x_1-x_2)[f(x_1)-f(x_2)] < 0$  

**图像特征**  
- 增函数：图像从左到右“上升”  
- 减函数：图像从左到右“下降”  

**判断方法**  
| 方法       | 步骤                                                                 |
|------------|----------------------------------------------------------------------|
| 定义法     | 1. 任取$x_1, x_2$且$x_1 < x_2$<br>2. 作差$f(x_1)-f(x_2)$<br>3. 判断符号<br>4. 得出结论 |
| 导数法     | 导数$f'(x) > 0$时递增，$f'(x) < 0$时递减（“正增负减”）               |
| 复合函数法 | 遵循“同增异减”原则                                                   |
