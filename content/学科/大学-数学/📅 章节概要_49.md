[00:03:30](https://getnotes.seek:210) **探寻数学源头的重要性之韦达定理**  
说话人强调学数学不应局限于公式、计算和做题，而要寻找源头。以韦达定理为例，对于方程\(AX² + BX + C = 0\)，若有两根\(X1\)、\(X2\)，则\(X1 + X2 = -B/A\)，\(X1×X2 = C/A\)，因韦达发现此规律得名。说话人表示若自己早出生，该定理可能叫“王氏定理”。接着讲解其原理，根据多项式分解法则，若方程有两根，多项式可分解为\(A×(X - X1)×(X - X2)\)，展开后对比同次项系数得出定理内容。掌握源头，即便忘记定理也能推导，还能类推到一元三次及N次方程根与系数关系，让听众认识到探寻数学源头对理解和拓展知识的重要性。
[00:06:18](https://getnotes.seek:378) **探寻数学源头的重要性之三角函数公式推导**  
说话人提到三角函数众多公式让学生痛苦，但数学无需死记硬背，抓住源头自己推导，知识会像自己发明的一样印象深刻。以三角函数公式推导为例，其源头基于单位圆。在单位圆中构建角度\(\alpha\)、\(\beta\)，通过两点间距离公式推导出\(\sin(\alpha - \beta)\)的公式。有了这个基础，可进一步推出\(\sin(\alpha + \beta)\)、\(\cos(\alpha - \beta)\)、\(\cos(\alpha + \beta)\)等公式。令\(\alpha = \beta\)，得出倍角公式，如\(\sin2\alpha = 2\sin\alpha\cos\alpha\) 、\(\cos2\alpha = \cos²\alpha - \sin²\alpha\)等，还能推出降幂公式。由\(\sin(\alpha + \beta)\)与\(\cos(\alpha + \beta)\)可推出正切两角和与差公式及二倍角正切公式等。通过详细推导过程，让听众明白把握数学源头能轻松学好数学。
