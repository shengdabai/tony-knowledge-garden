# 向量数乘

- **定义**：实数$\lambda$与向量$\vec{a}$的积是一个向量，记作$\lambda\vec{a}$。  
- **性质**：  
  - $|\lambda\vec{a}| = |\lambda||\vec{a}|$；  
  - $\lambda > 0$时，$\lambda\vec{a}$与$\vec{a}$方向相同；$\lambda < 0$时，方向相反；$\lambda = 0$时，$\lambda\vec{a} = \vec{0}$。  
- **运算律**：  
  - $\lambda(\mu\vec{a}) = (\lambda\mu)\vec{a}$  
  - $(\lambda + \mu)\vec{a} = \lambda\vec{a} + \mu\vec{a}$  
  - $\lambda(\vec{a} + \vec{b}) = \lambda\vec{a} + \lambda\vec{b}$  

🔗 **重要定理与公式**  
- **共线定理**：向量$\vec{b}$与非零向量$\vec{a}$共线$\iff$存在唯一实数$\lambda$，使$\vec{b} = \lambda\vec{a}$（$\vec{a} \neq \vec{0}$）。  
- **中点公式**：若$M$为线段$AB$的中点，则$\overrightarrow{OM} = \frac{1}{2}(\overrightarrow{OA} + \overrightarrow{OB})$。  
- **向量等式**：$\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$，$\overrightarrow{OA} - \overrightarrow{OB} = \overrightarrow{BA}$。  

⚠️ **学习误区**  
1. **忽视零向量**：零向量方向任意，与任何向量平行，易与实数0混淆。  
2. **概念混淆**：  
   - 向量平行≠向量相等（相等向量一定平行，平行向量不一定相等）；  
   - 向量平行与直线平行不同（直线平行不包含重合，向量平行包含共线）。  
3. **运算错误**：类比数的运算时忽略向量方向，如$|\vec{a} + \vec{b}| \leq |\vec{a}| + |\vec{b}|$中等号成立条件。  

💡 **知能提升**  
- **用向量解决平面几何问题的步骤**：  
  1. 建立联系：用向量表示几何元素；  
  2. 向量运算：研究平行、垂直、距离、夹角等；  
  3. 转化结论：将运算结果“翻译”为几何关系。
