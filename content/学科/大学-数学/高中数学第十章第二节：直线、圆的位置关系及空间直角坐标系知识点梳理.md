📌 **圆的切线方程**  
- **过圆上一点的切线方程**  
  - 对于圆 \(x^2 + y^2 = r^2\)，过切点 \((x_1, y_1)\) 的切线方程：\(x_1x + y_1y = r^2\)  
  - 对于圆 \((x-a)^2 + (y-b)^2 = r^2\)，过切点 \((x_1, y_1)\) 的切线方程：\((x_1-a)(x-a) + (y_1-b)(y-b) = r^2\)  
  - 对于圆 \(x^2 + y^2 + Dx + Ey + F = 0\)，过切点 \((x_1, y_1)\) 的切线方程：\(x_1x + y_1y + D\frac{x_1+x}{2} + E\frac{y_1+y}{2} + F = 0\)  

- **过圆外一点的切线方程**  
  - **代数法**：设切点 \(P(x_1, y_1)\)，联立方程组 \(\begin{cases}(x_1-a)^2 + (y_1-b)^2 = r^2 \\ (x_1-a)(x_0-a) + (y_1-b)(y_0-b) = r^2\end{cases}\) 求解  
  - **几何法**：设切线方程为 \(y - y_0 = k(x - x_0)\)，由圆心到切线距离等于半径 \(\frac{|ka - b - kx_0 + y_0|}{\sqrt{k^2 + 1}} = r\) 求斜率 \(k\)  

- **切线长公式**  
  圆 \(x^2 + y^2 + Dx + Ey + F = 0\) 外一点 \(P(x_1, y_1)\) 向圆引切线，切线长为 \(\sqrt{x_1^2 + y_1^2 + Dx_1 + Ey_1 + F}\)
