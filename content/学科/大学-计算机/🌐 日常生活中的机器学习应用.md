# **🌐 日常生活中的机器学习应用**

| **应用场景** | **具体案例** | **技术原理** |
| :--- | :--- | :--- |
| **搜索引擎** | Google/Bing/Baidu网页搜索排序 | 基于用户行为和内容相关性的**网页排名算法** |
| **社交媒体** | Instagram/Snapchat好友照片自动识别与标签 | **图像识别技术**（人脸识别、特征提取） |
| **视频推荐** | 流媒体平台电影/剧集推荐系统 | **协同过滤算法**（基于用户历史偏好匹配） |
| **语音交互** | 手机语音转文字（如"hey Andrew, how's it going"）、Siri/Google语音助手 | **自然语言处理**（语音识别+语义理解） |
| **垃圾邮件过滤** | 邮件服务自动标记"恭喜获得百万美元"等垃圾邮件 | **文本分类算法**（基于关键词和内容特征识别） |
