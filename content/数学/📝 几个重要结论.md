# 📝 几个重要结论

- 首尾相接的若干向量构成一个封闭图形，则它们的和为0，如`\[ \overrightarrow{MN} = \overrightarrow{MA} + \overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} + \overrightarrow{DN} \]`
- `\[ ||\boldsymbol{a}| - |\boldsymbol{b}|| \leq |\boldsymbol{a} + \boldsymbol{b}| \leq |\boldsymbol{a}| + |\boldsymbol{b}| \]`
- 平面向量的多边形法则在空间也成立
